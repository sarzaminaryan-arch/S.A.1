# Sarzamin Aryan — Gahar Lake Featured View Importer

افزونه نصب‌پذیر وردپرس برای ساخت/به‌روزرسانی مقاله «نمای برتر دریاچه گهر دورود» در قالب فرزند سرزمین آریان.

## خروجی در وردپرس

- ایجاد/به‌روزرسانی CPT `attraction` با نامک `gahar-lake-dorud`
- اتصال به شهرستان دورود و استان لرستان
- درج مقاله کامل مسیر دورود به دریاچه گهر، امکانات، خطرات، کمپ و برنامه سفر
- ثبت تصویر شاخص طبق خواسته کاربر: کادر سفید با متن فارسی بولد، خط رنگی و متن انگلیسی `Gahar lake - Dorud city - lorestan`
- تکمیل فیلدهای شناسنامه «نمای برتر»
- تکمیل سئو و Rank Math
- تکمیل FAQ ساختاریافته
- ثبت منابع دارای لینک

## روش استفاده

1. فایل ZIP انتشار را از GitHub دانلود کنید.
2. در وردپرس از مسیر «افزونه‌ها → افزودن → بارگذاری افزونه» نصب و فعال کنید.
3. در صفحه «افزونه‌ها»، در ردیف این افزونه روی «درون‌ریزی مقاله دریاچه گهر» کلیک کنید.
4. پس از اجرا، به صفحه ویرایش مقاله هدایت می‌شوید.

این افزونه مانند ایمپورترهای قبلی از اکشن مستقیم ردیف افزونه‌ها در `plugins.php` و هوک `admin_init` استفاده می‌کند تا به مسیر اجرایی جداگانه و احتمال ۴۰۴ وابسته نباشد.
