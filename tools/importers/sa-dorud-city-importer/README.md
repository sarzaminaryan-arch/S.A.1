# Sarzamin Aryan — Dorud City Article Importer

افزونه نصب‌پذیر وردپرس برای ساخت/به‌روزرسانی مقاله شهرستان دورود در قالب فرزند سرزمین آریان.

## خروجی در وردپرس

- به‌روزرسانی نوشته CPT `city` با نامک `dorud`
- ثبت رابطه با استان لرستان
- درج متن بازنویسی‌شده درباره جاذبه‌های دورود
- ثبت تصویر شاخص ۱۲۰۰×۶۰۰ سبک و نمادین
- تکمیل فیلدهای سئو و Rank Math
- تکمیل FAQ ساختاریافته
- ثبت منابع دارای لینک برای عبور از دروازه انتشار

## روش استفاده

1. فایل ZIP انتشار را از GitHub دانلود کنید.
2. در وردپرس از مسیر «افزونه‌ها → افزودن → بارگذاری افزونه» نصب و فعال کنید.
3. در صفحه «افزونه‌ها»، در ردیف این افزونه روی «درون‌ریزی مقاله دورود» کلیک کنید.
4. پس از اجرا، به صفحه ویرایش مقاله دورود هدایت می‌شوید.

این افزونه برای مشکل ۴۰۴ مسیرهای اجرایی، از اکشن مستقیم ردیف افزونه‌ها روی `plugins.php` و `admin_init` استفاده می‌کند.
