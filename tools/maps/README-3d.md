# tools/maps — نقشهٔ سه‌بعدی استان‌ها

ساخت نقشهٔ سه‌بعدی هر استان با مرز شهرستان‌ها، به سبک داشبورد تیره: هر شهرستان یک
ستون با ارتفاع متناسب با مساحتش، نمای بالا با گرادیان آبی، نمای کناری با سایه‌روشن
(نور از بالا-چپ) و خط لبهٔ نارنجی.

این نسخه از `make_province_maps.py` جداست: آن یکی نقشهٔ تخت مرزی می‌سازد، این یکی
نمای ایزومتریک با ارتفاع.

## اجرا

```bash
python3 tools/maps/make_province_3d.py                  # هر ۳۱ استان (~۳۵ ثانیه)
python3 tools/maps/make_province_3d.py --only fars,kerman
python3 tools/maps/make_province_3d.py --no-labels      # فقط مرزها، بدون نام
python3 tools/maps/make_province_3d.py --check
```

خروجی در `outputs/province-3d/` است؛ این پوشه در `.gitignore` است و کامیت نمی‌شود.

## تصویربرداری

تصویربرداری ایزومتریک با فرمول دستی و الگوریتم دکمهٔ نقاش (رسم از دورترین به
نزدیک‌ترین) پیاده شده، **نه** `mplot3d` — ترتیب عمق در mplot3d برای چندضلعی‌های
متقاطع قابل اتکا نیست و نقشه را به‌هم می‌ریزد.

همه‌چیز پیش از تصویربرداری به تصویر معادل آلبرز ایران می‌رود تا شکل درست بماند؛
ارتفاع ستون‌ها نسبت به بزرگی خودِ استان سنجیده می‌شود (واحد مختصات متر است، پس ارتفاع
«مطلق» یعنی عددی که در نقشه دیده نمی‌شود).

## داده و مرزها

| | |
| --- | --- |
| مرز استان | `ssepehrnoush/Iran-geojson-map-boundaries` (ODbL) |
| مرز شهرستان | `hosseinhabibi2004/iran-geojson` — استخراج Overpass (ODbL) |
| نام شهرستان | `data/counties.php` مخزن — نامک و نام فارسی |
| انتساب لازم | `© OpenStreetMap contributors` |

نگاشت «پوشهٔ دادهٔ شهرستان → استان» **در کد ثابت نشده**؛ در هر اجرا از روی خودِ داده
استخراج می‌شود (نام شهرستان‌های هر پوشه با مرجع مخزن تطبیق داده می‌شود). اگر یک روز
شماره‌گذاری پوشه‌ها عوض شود، ابزار خودش را دوباره کشف می‌کند.

شهرستان‌ها به مرز استان **بریده** می‌شوند. بدون این کار، شهرستان‌های ساحلی چون
بندرعباس و بوشهر که در OSM آب‌های سرزمینی دارند، لکه‌های دورافتاده بیرون کادر می‌سازند.

## وضعیت دادهٔ شهرستان‌ها

این را باید بدانید: **اسنپ‌شات OSM قدیمی‌تر از فهرست رسمی مخزن است.**

* مرجع مخزن ۴۸۳ شهرستان دارد؛ دادهٔ OSM ۴۷۸ شهرستانِ قابل تطبیق.
* ۱۵ نام OSM قدیمی است و به مرجع مخزن نمی‌خورد. ابزار آن‌ها را چاپ می‌کند و از ترسیم
  کنار می‌گذارد — **نه** اینکه خودسرانه به نام رسمی برگرداند. نمونه‌ها:

  | نام در OSM | نام رسمی فعلی |
  | --- | --- |
  | بندر انزلی | انزلی |
  | طرقبه شاندیز | شاندیز |
  | فریدون شهر | فریدون‌شهر (هم‌نام، تفاوت نیم‌فاصله) |
  | طوالش | بندر طوالش |
  | مانه و سملقان | مانه و سملقان (ادغام جدیدتر) |
  | کوه‌چنار | جلال‌آباد و کوه‌چنار (ادغام) |

* نام انگلیسی: ۴۶۰ شهرستان `name:en` دارند و ۳ تای دیگر (گنبکی، جازموریان، مروست) ندارند.
  مرجع مخزن اساساً ستون انگلیسی ندارد، پس هر نام انگلیسی که بیرون بیاید از تگ OSM است
  و ممکن است با رومنی‌نویسی رسمی فرق داشته باشد.

روی نقشه **نام انگلیسی** شهرستان می‌آید (پیش‌فرض `--label-lang en`، از تگ `name:en` در
OSM) و پسوند `County` حذف می‌شود تا جای برچسب باز شود: `Abadeh County` → `Abadeh`.
عنوان بالای نقشه هم انگلیسی است: `Fars Province` و زیر آن `Iran · 36 counties`.

با `--label-lang fa` برچسب‌ها فارسی می‌شوند (از مرجع مخزن، نه از OSM). در آن حالت نیم‌فاصله
حفظ می‌شود: چون `arabic_reshaper` نیم‌فاصله را حذف می‌کند و دو واژه را به هم می‌چسباند
(«چنگه‌ماغانه» → «چنگهماغانه»)، نیم‌فاصله موقتاً به یک نویسهٔ نامتغیر می‌رود و در پایان
برگردانده می‌شود.

## گزینه‌ها

| پرچم | کار |
| --- | --- |
| `--only slug,…` | فقط این نامک‌ها |
| `--out DIR` | پوشهٔ خروجی |
| `--size W H` / `--dpi N` | اندازهٔ بوم و وضوح |
| `--azimuth` / `--elevation` | زاویهٔ چرخش و بلندی دید |
| `--height` | ارتفاع بزرگ‌ترین ستون، نسبت به بزرگی استان (پیش‌فرض ۰٫۱۱) |
| `--height-power` | ۰ = ارتفاع یکنواخت، ۰٫۵ = متناسب با جذر مساحت |
| `--label-size` / `--min-label` | اندازهٔ نام و کمینهٔ سهم مساحت برای نمایش |
| `--label-lang en\|fa` | زبان برچسب‌ها و عنوان؛ پیش‌فرض `en` |
| `--no-labels` | بدون نام روی نقشه (نام فایل می‌ماند) |
| `--check` | فقط گزارش وضعیت خروجی |
