# tools/maps — نقشهٔ استان‌های ایران

ساخت نقشهٔ هر یک از ۳۱ استان از روی مرزهای GeoJSON: مرز استان پررنگ، استان‌های همسایه
کم‌رنگ به‌عنوان زمینه، نام فارسی و انگلیسی در پایین نقشه، و خط انتساب منبع داده.
خروجی هر استان یک PNG با ۳۰۰ dpi و یک SVG است.

این ابزار **لایهٔ خیابان ندارد**. نسخهٔ اولیه با `osmnx.graph_from_polygon` خیابان‌های
OSM را می‌کشید؛ آن بخش به این نسخه نیامده چون هم به سرویس Overpass وابسته است و هم برای
۳۱ استان (بعضی استان‌ها بیش از یک میلیون گره) زمان‌بر و شکننده است. اگر روزی نقشهٔ خیابانی
خواسته شد، باید لایهٔ جاده جداگانه و با کش per-province اضافه شود — در وضعیت فعلی مرزها
از OSM گرفته می‌شوند و همین برای نمایش شکل استان کافی است.

## اجرا

```bash
python3 tools/maps/make_province_maps.py                    # هر ۳۱ استان
python3 tools/maps/make_province_maps.py --only lorestan,kerman
python3 tools/maps/make_province_maps.py --contact-sheet    # یک تصویر از همه
python3 tools/maps/make_province_maps.py --check            # بدون ساخت؛ وضعیت خروجی
python3 tools/maps/make_province_maps.py --list             # فهرست نامک‌ها
python3 tools/maps/make_province_maps.py --geojson path/to/boundaries.geojson
```

خروجی پیش‌فرض در `outputs/province-maps/` است؛ این پوشه در `.gitignore` قرار دارد و
طبق سیاست مخزن (AGENTS.md بند ۷) هیچ تصویر تولیدشده‌ای کامیت نمی‌شود.

## مرجع نام‌ها

نام استان‌ها از `wp-content/themes/sarzaminaryan-child/data/provinces.php` خوانده می‌شود
(نامک + نام فارسی + نام انگلیسی + شهر مرکز) — **نه** از ستون `name` فایل GeoJSON. دلیلش این
است که آن ستون بین نگارش‌های مختلف داده عوض می‌شود و نام فارسی را با «استان البرز، ایران»
یا با کاراکترهای جهت‌دهی می‌دهد.

تطبیق مرزها با نام نرمال‌شده انجام می‌شود (`norm()`): نیم‌فاصله، کاراکترهای جهت‌دهی
(ZWNJ/RLE/RTL…) و «ي/ك» عربی بی‌اثر می‌شوند، اول نام فارسی و بعد نام انگلیسی امتحان
می‌شود. روی دادهٔ فعلی، ۳۰ استان با نام فارسی و یکی (کهگیلویه و بویراحمد) با نام انگلیسی
تطبیق می‌یابد. اگر مرز استانی پیدا نشود، نامش چاپ و — با `--strict` — اجرا کد ۲ می‌گیرد.

## منبع داده و پروانه

| | |
| --- | --- |
| داده | `ssepehrnoush/Iran-geojson-map-boundaries` → `ir_states_boundaries_coordinates.geojson` |
| سرچشمه | OpenStreetMap (استخراج Mapzen) |
| پروانهٔ داده | ODbL 1.0 |
| انتساب لازم | `© OpenStreetMap contributors` |

ODbL انتشار نقشه را بدون ذکر انتساب مجاز نمی‌داند؛ همین انتساب پایین هر نقشه چاپ می‌شود.
با `--attribution` می‌توان متن دلخواه گذاشت، ولی حذفش خلاف پروانه است.

فایل مرزها در `~/.cache/sa-province-maps/` کش می‌شود (متغیر `SA_MAP_CACHE`) و در نبودش از
`raw.githubusercontent.com` و در صورت شکست از مسیر `codeload` گرفته می‌شود، پس روی شبکه‌ای
که یکی از این دو مسیر بسته باشد هم کار می‌کند.

## گزینه‌ها

| پرچم | کار |
| --- | --- |
| `--only slug,…` | فقط این نامک‌ها |
| `--out DIR` | پوشهٔ خروجی |
| `--formats png,svg` | قالب‌های خروجی |
| `--prefix map-` | پیشوند نام فایل |
| `--size W H` | اندازهٔ بوم به اینچ (پیش‌فرض ۱۰×۱۰) |
| `--dpi N` | وضوح PNG (پیش‌فرض ۳۰۰) |
| `--no-context` | استان‌های همسایه رسم نشوند |
| `--no-project` | بدون تصویر معادل؛ مختصات خام درجه (رفتار اسکریپت اولیه) |
| `--centers FILE` | JSON مختصات مستند شهرهای مرکزی: `{"centers": {"qom": [50.88, 34.70]}}` |
| `--contact-sheet` | یک تصویر از همهٔ ۳۱ استان (کاشی‌های مربع و هم‌اندازه) |
| `--check` | فقط گزارش وضعیت خروجی‌ها |
| `--list` | فهرست نامک‌ها |
| `--strict` | با پیدا نشدن همهٔ مرزها، توقف با کد ۲ |
| `--geojson PATH` / `--refresh` | فایل مرز دلخواه / نادیده‌گرفتن کش |

کدهای خروج: `۰` موفق، `۱` بخشی از استان‌ها ساخته نشد یا `--check` ناقص بود،
`۲` ورودی نامعتبر یا مرزهای ناقص (با `--strict`).

## تصویر معادل

پیش‌فرض روی مخروط آلبرتِ هم‌مساحت ایران (عرض مرجع ۲۹٫۵ و ۳۵٫۵ درجه، نصف‌النهار میانی ۵۳ درجه)
تبدیل می‌شود؛ بدون این تبدیل، طول جغرافیایی روی نقشه کشیده می‌شود چون درجهٔ طول در عرض ۳۲
درجه کوتاه‌تر از درجهٔ عرض است. `--no-project` رفتار اسکریپت اولیه را برمی‌گرداند.

## نیازمندی‌ها

```bash
pip install --break-system-packages geopandas matplotlib pyproj
```

قلم فارسی (وازیرمتن) از بستهٔ npm وازیرمتن در `~/.cache/sa-fonts/` کش می‌شود
(متغیر `SA_FONT_DIR`)؛ در نبود قلم یا نبود شبکه، ساخت متوقف نمی‌شود و فقط برچسب فارسی
حذف می‌شود. هیچ فایل قلمی داخل مخزن نگه داشته نمی‌شود.

## تست

```bash
python3 -m pytest tests/test_province_maps.py -q
```

تست‌ها نرمال‌سازی نام و خواندن مرجع استان‌ها را می‌سنجند و به شبکه و geopandas نیاز ندارند.

## نکتهٔ داده

مختصات شهرهای مرکزی در این ابزار **حدس زده نمی‌شود** (همان سیاستی که `data/borders.php`
برای وضعیت منبع رعایت می‌کند). تا وقتی فایل مختصات مستندی با `--centers` داده نشود،
نشانهٔ شهر مرکزی رسم نمی‌شود.
