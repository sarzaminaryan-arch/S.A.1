# tools/maps — نقشهٔ شهری قم و فارس به سبک deMAr

ابزار دوم نقشه در این پوشه. `make_province_maps.py` نقشهٔ تخت مرزی می‌سازد،
`make_province_3d.py` نقشهٔ ایزومتریک، و **این یکی نقشهٔ کارتایوگرافیک شهری**
می‌سازد — همان زبان بصری نمونه‌های deMAr: پهنه‌های رنگی، سلسله‌مراتب جاده و
قابِ عنوانِ حاشیه‌نویسی.

پیش‌فرض فقط **قم** و **فارس** است، در **دو مدل**.

## دو مدل

| مدل | زمین | جنگل/پارک | بافت شهری | جاده | قاب عنوان |
| --- | --- | --- | --- | --- | --- |
| `sand` | کرم `#ece6d6` | سبز زیتونی | بژ گرم | جوهر سیاه | مشکی |
| `ink` | آبی‌فام روشن | سبز خاکستری | نارنجی مرجانی | جوهر سرمه‌ای | نارنجی `#dd6230` |

هر دو مدل **هم خیابان‌های شهری و هم جاده‌ها** را می‌کشند، با سلسله‌مراتب ضخامت
جدا: بزرگراه ۳٫۴ ← تریانری ۱٫۰ ← خیابان مسکونی ۰٫۶۲ ← راه Service ۰٫۳۶.
بزرگراه و راه اصلی «کاسینگ» مشکی دارند و روی آن پرچم روشن کشیده می‌شود، دقیقاً
مثل نمونه‌ها.

## اجرا

```bash
python3 tools/maps/make_city_maps.py                      # قم و فارس، هر دو مدل
python3 tools/maps/make_city_maps.py --only fars --styles ink
python3 tools/maps/make_city_maps.py --size 16 20 --dpi 300   # برای چاپ بزرگ
python3 tools/maps/make_city_maps.py --check
python3 tools/maps/make_city_maps.py --refresh            # دوریز کردن حافظهٔ نهان
```

خروجی در `outputs/province-city/` است؛ در `.gitignore`.

## لایهٔ خیابان: Overpass

دادهٔ خیابان از **Overpass API** گرفته می‌شود (`out geom`، یک پرس‌وجو برای
`highway`، `landuse`، `natural`، `leisure`، `waterway`) و در
`~/.cache/sa-province-maps/streets/<slug>.json` کش می‌شود. سه نشانی به‌ترتیب
امتحان می‌شوند و هرکدام دو بار تلاش می‌کند.

اگر Overpass در دسترس نباشد (شبکهٔ بسته، فیلتر، DNS بلاک — مثل محیط CI یا
این sandbox) ابزار:

* یک هشدار واضح چاپ می‌کند،
* **فقط مرز شهرستان‌ها** را می‌کشد و پسوند `-nostreets` به نام فایل می‌زند،
* و بالای نقشه می‌نویسد `OSM STREET LAYER UNAVAILABLE — COUNTY BOUNDARIES ONLY`.

ابزار **هرگز جادهٔ ساختگی نمی‌سازد**. با `--require-streets` در نبودِ داده خطا
می‌دهد تا در خط تولید متوجه نشویم.

## گزینه‌ها

| پرچم | کار |
| --- | --- |
| `--only qom,fars` | استان‌ها (پیش‌فرض قم و فارس) |
| `--styles sand,ink` | مدل‌ها |
| `--out DIR` | پوشهٔ خروجی |
| `--size W H` / `--dpi N` | اندازهٔ بوم و وضوح |
| `--margin` | حاشیهٔ کادر نقشه |
| `--require-streets` | بدون Overpass خطا بده |
| `--refresh` | حافظهٔ نهان خیابان را دوباره بگیر |
| `--check` | فقط گزارش وضعیت |

## داده و مرزها

| | |

| مرز استان | `ssepehrnoush/Iran-geojson-map-boundaries` (ODbL) |
| مرز شهرستان | `hosseinhabibi2004/iran-geojson` — استخراج Overpass (ODbL) |
| خیابان/کاربری/پارک/آب | Overpass API، پرس‌وجوی همین ابزار |

هندسهٔ خیابان با همان تصویر معادل آلبرزِ `make_province_3d.py` تصویر می‌شود و
به مرز استان برش می‌خورد، پس با نقشهٔ سه‌بعدی هم‌مقیاس می‌ماند.

```bash
python3 -m pytest tests/test_city_maps.py -q
```

تست‌ها ساخت پرس‌وجو، تبدیل پاسخ Overpass به هندسهٔ تصویرشده، رندر هر دو مدل با
دادهٔ ساختگی، و رفتار «بدون خیابان» را پوشش می‌دهند.
