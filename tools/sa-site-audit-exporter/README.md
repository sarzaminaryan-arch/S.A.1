# SA Site Audit Exporter — نسخهٔ 1.0.0

افزونهٔ سبک و **فقط‌خواندنی** برای تهیهٔ دو فایل ممیزی از سایت سرزمین آریان:

1. **فهرست محتوا (JSON):** صفحات عمومی منتشرشده، متن ذخیره‌شده، عنوان/نامک/URL، روابط انتخاب‌شده، SEO metaهای allowlist، taxonomyهای عمومی، آمار heading/link و شمار محتوا.
2. **نمونهٔ HTML زنده (JSON):** مرورگر مدیر، روی همان دامنهٔ وردپرس، `robots.txt` و چند نشانی رایج sitemap، صفحهٔ اصلی، آرشیوها، استان‌ها/دیدنی‌های منتشرشده، یک شهرستان نمونه از هر استان و حداکثر پنج نوشته را می‌خواند؛ عنوان، description، canonical، robots، H1/H2، schema، پیوندهای داخلی و status پاسخ را ثبت می‌کند.

## امنیت و حریم خصوصی

- فقط کاربری با capability `manage_options` می‌تواند از ابزار استفاده کند؛ فرم خروجی nonce دارد.
- فقط post type عمومی و رکوردهای `publish` صادر می‌شوند. پیش‌نویس/خصوصی، دیدگاه، سفارش، کاربر، حساب/رمز، همهٔ options و همهٔ metaها صادر نمی‌شوند.
- فیلدهای meta از فهرست محدود و صریح انتخاب شده‌اند؛ metaهای دیگر خارج می‌مانند.
- افزونه هیچ POST/ارسالی به خارج از سایت، CDN، Analytics، API ثالث یا مقصد بیرونی ندارد.
- crawl در مرورگر کاربر، با `fetch` همان‌مبدأ به URLهای تولیدشده از همین سایت اجرا می‌شود؛ redirect خودکار دنبال نمی‌شود تا حتی تغییرمسیر خارجی هم باعث درخواست به دامنهٔ دیگر نشود. متن کامل HTML ذخیره/ارسال نمی‌شود؛ فقط خلاصهٔ ساختاری صفحه و لینک‌ها در فایل دانلودی قرار می‌گیرد.
- افزونه در activation هیچ option، جدول یا محتوایی نمی‌سازد؛ خروجی فقط هنگام کلیک مدیر ساخته و مستقیم دانلود می‌شود.
- محتوای منتشرشده ممکن است اطلاعاتی داشته باشد که مالک نمی‌خواهد در فایل خروجی به اشتراک بگذارد؛ پیش از پیوست‌کردن JSONها یک بازبینی سریع انجام دهید.

## نصب

1. فایل ZIP انتشار GitHub را از پیوندی که Agent ارائه می‌کند دریافت کنید.
2. در WordPress: **افزونه‌ها ← افزودن افزونه ← بارگذاری افزونه**، ZIP را انتخاب و نصب کنید؛ سپس فعال‌سازی.
3. به **ابزارها ← خروجی ممیزی سایت** بروید.

## گرفتن فایل‌ها

1. **ساخت و دریافت فهرست محتوا (JSON)** را بزنید. فایل `sa-site-audit-YYYY-MM-DD.json` دانلود می‌شود.
2. **شروع بررسی HTML زنده** را بزنید. نوار وضعیت پیشرفت را نشان می‌دهد؛ در پایان فایل `sa-site-rendered-audit-YYYY-MM-DD.json` دانلود می‌شود.
3. هر دو فایل را در گفت‌وگوی Arena پیوست کنید. اگر حجم زیاد بود، `limits.truncated` را در فایل فهرست بررسی کنید و به Agent اطلاع دهید.
4. بعد از گرفتن فایل‌ها، اگر دیگر لازم ندارید، افزونه را غیرفعال و حذف کنید؛ هیچ داده‌ای در سایت ذخیره نشده است.

## محدودیت‌ها

- فهرست محتوا شامل متن ذخیره‌شدهٔ WordPress است، نه خروجی نهایی قالب. برای همین فایل دوم، نمونهٔ زندهٔ HTML را از مرورگر می‌سنجد.
- crawl زنده شامل همهٔ 483 شهرستان نیست؛ یک نمونهٔ منتشرشده از هر استان انتخاب می‌کند تا خروجی سریع و کم‌فشار بماند. فایل اول همچنان تمام پست‌های عمومی منتشرشده را تا سقف 5000 رکورد فهرست می‌کند.
- اگر پیشخوان با دامنه‌ای متفاوت از `home_url()` باز باشد (مثلاً www در یکی و بدون www در دیگری)، crawl متوقف می‌شود. از همان hostname اصلی سایت وارد پیشخوان شوید.
- اگر میزبان درخواست‌های متعدد را محدود کند، crawl را می‌توان متوقف کرد و فایل partial دانلود می‌شود.
- این ابزار اطلاعات GA4 یا Search Console را صادر نمی‌کند؛ آن‌ها را جداگانه از سرویس خودشان دریافت کنید، اگر لازم شد.
