== Description ==

Sarzamin Aryan is a lightweight, RTL-first classic parent theme reviewed against WordPress Theme
Review requirements and Google page-experience guidelines. All project features (custom post
types for provinces/cities/attractions/routes/foods/souvenirs, meta boxes, SEO output, JSON-LD,
breadcrumbs, Jalali dates) live in the child theme `sarzaminaryan-child` — activate the child.

* No external requests: Vazirmatn font bundled (SIL OFL 1.1).
* Logical CSS properties; no double-flip RTL hacks.
* Accessible: skip link, screen-reader text, visible focus, aria-controlled menu/search toggles.
* Performance: 3 small stylesheets, one deferred script, font preload, no jQuery.

== Installation ==

1. Upload `sarzaminaryan.zip` via Appearance → Themes → Add New → Upload Theme (or extract into wp-content/themes/ with cPanel File Manager).
2. Upload and activate `sarzaminaryan-child.zip` the same way.
3. Go to Appearance → Customize → Theme Options to set the footer text.
