### ۱. ریشه‌ی «نصف صفحه از قاب بیرون می‌زند»

هیچ محافظی در برابر سرریز افقی در قالب نبود. کافی است **یک** عنصر چند پیکسل
از عرض ویوپورت بزند بیرون تا کل سند پهن شود؛ آن‌وقت همه‌چیز — از جمله کادر
جست‌وجو — به نظر می‌رسد از قاب زده بیرون، در حالی که خودش سالم است.

```css
html, body { max-width: 100%; overflow-x: clip; }
img, svg, video, iframe, table, pre { max-width: 100%; }
```

`clip` و نه `hidden`: `overflow:hidden` روی `html`/`body` هدر `position:sticky`
را می‌شکند.

سه منبع مشخص سرریز هم جداگانه بسته شد:

- `.sa-hw > * { min-width: 0 }` — آیتم گرید به‌طور پیش‌فرض `min-width:auto` دارد
  و زیر اندازه‌ی محتوایش جمع نمی‌شود. کلاسیک‌ترین علت سرریز گرید.
- `.sa-hf-brand` از `flex: none` به `flex: 0 1 auto` + `min-width: 0` تغییر کرد.
  با `flex:none`، برندِ هدر هرگز جمع نمی‌شد.
- `.sa-hero h1` و `.sa-brand` حالا `min-width:0` و `overflow-wrap:anywhere` دارند.
