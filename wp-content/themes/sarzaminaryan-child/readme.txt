قالب فرزند «سرزمین آریان» (sarzaminaryan.ir) — دانشنامه‌ی سفر ایران. تمام امکانات پروژه در همین قالب پیاده شده است و به هیچ افزونه‌ای نیاز ندارد.

== Description ==

* ۶ نوع محتوای اختصاصی طبق مدل داده v1.0: استان، شهر، جاذبه، مسیر سفر، غذای محلی، سوغات (اقامتگاه رزرو شده؛ با ثابت `SA_ENABLE_ACCOMMODATION` فعال می‌شود).
* طبقه‌بندی‌ها: استان (۳۱ استان از پیش ساخته می‌شود)، نوع جاذبه، فصل سفر، بودجه، مدت سفر.
* جعبه‌های ویرایش: اطلاعات موجودیت، روابط (استان/شهر/جاذبه‌های مرتبط)، سئو (عنوان، توضیح، کلیدواژه، OG، کنونیکال، noindex)، سوالات متداول، منابع.
* دروازه‌ی انتشار (Level 7): مطلب ناقص منتشر نمی‌شود و به پیش‌نویس برمی‌گردد (قابل تغییر به حالت هشدار در سفارشی‌سازی).
* سئوی داخلی: title/description/canonical/OG/Twitter، JSON-LD (Organization، WebSite، BreadcrumbList، TouristAttraction، AdministrativeArea، City، Trip، Recipe/Product، FAQPage، Article)، بردکرامب، نقشه‌ی سایت هسته با اولویت‌بندی.
* تاریخ شمسی و اعداد فارسی (قابل خاموش‌کردن)، اسلاگ انگلیسی خودکار.
* امنیت: حذف نسخه، غیرفعال‌سازی XML-RPC و فهرست کاربران REST، هدرهای امنیتی، محدودیت ورود.
* کارایی: حذف ایموجی/oEmbed اضافی، lazy-loading، preload فونت، سایز تصویر hero.
* صفحه‌ی اول با قهرمان، آمار، ۳۱ استان، جاذبه‌ها، مسیرها، غذاها، سوغات و آخرین مطالب — همه از «سفارشی‌سازی → سرزمین آریان» قابل تنظیم.

== Installation ==

1. ابتدا قالب والد `sarzaminaryan.zip` را از «نمایش → پوسته‌ها → افزودن → بارگذاری پوسته» نصب کنید (فعال نکنید).
2. سپس `sarzaminaryan-child.zip` را بارگذاری و **فعال** کنید.
3. با فعال‌سازی، ۳۱ استان، طبقه‌بندی‌ها، صفحات (خانه، وبلاگ، درباره‌ی ما، تماس، سیاست تحریریه)، دو منو و پیوندهای یکتا به‌صورت خودکار ساخته می‌شوند.
4. اگر صفحه‌ای ۴۰۴ داد: تنظیمات → پیوندهای یکتا → ذخیره.
5. لوگو، تصویر قهرمان، شبکه‌های اجتماعی و متن پابرگ را از «سفارشی‌سازی → سرزمین آریان» تنظیم کنید.

== GitHub Updates ==

1. چون مخزن خصوصی است، از «نمایش → به‌روزرسان گیت‌هاب» یک Fine-grained GitHub token فقط‌خواندنی ثبت کنید؛ روش امن‌تر تعریف `SA_GITHUB_TOKEN` در `wp-config.php` است.
2. دکمه‌ی «بررسی هم‌اکنون» را بزنید. نسخه‌های تازه در «پیشخوان → به‌روزرسانی‌ها» ظاهر می‌شوند.
3. توکن داخل قالب یا بسته‌های انتشار قرار نمی‌گیرد. هر نصب وردپرس باید توکن دسترسی خودش را تنظیم کند.
