استخراج دقیق مقاله‌های منتشرشدهٔ سایت زنده و تطبیق فیلدبه‌فیلد با خط مبنای مخزن S.A.1؛ کاملاً فقط‌خواندنی.

== Description ==
* از «ابزارها ← ممیزی مقالات زنده» نوع‌های محتوا (نوشته، دیدنی، شهرستان، استان و…) انتخاب می‌شوند؛ فقط نوشته‌های منتشرشده خوانده می‌شوند.
* برای هر مقاله: شناسه و نامک، عنوان، تاریخ‌ها، نویسنده، پیوند، متن کامل و سه هش (خام، نرمال، متن ساده)، تیترها، لینک‌ها، تصاویر داخل متن، طبقه‌بندی‌ها، متاها، FAQ، تصویر شاخص و روابط استان/شهرستان استخراج می‌شود.
* خط مبنا از سه منبع می‌آید: دادهٔ «مقالات آماده»ی قالب فرزند (sa_ready_articles_data)، اسنپ‌شات مخزن همراه افزونه (data/baseline.json) یا فایل JSON بارگذاری‌شده.
* تطبیق با کلید «نوع محتوا + نامک» انجام می‌شود و خروجی چهار دسته است: یکسان، دارای اختلاف (فیلدبه‌فیلد)، فقط در سایت، فقط در مخزن؛ کلیدهای تکراری هم جدا هشدار داده می‌شوند.
* اسنپ‌شات زنده و گزارش تطبیق هر دو به‌صورت JSON و CSV قابل دانلودند.
* هیچ نوشته، متا، ترم یا تنظیمی تغییر نمی‌کند؛ هیچ مسیر REST عمومی ساخته نمی‌شود و هیچ درخواست خارجی ارسال نمی‌شود. همهٔ عملیات نیازمند manage_options و نانس است.

== Installation ==
1. فایل ZIP را در «افزونه‌ها ← افزودن ← بارگذاری افزونه» بارگذاری و فعال کنید.
2. از «ابزارها ← ممیزی مقالات زنده» نوع‌های محتوا و منبع خط مبنا را انتخاب و «اجرای تطبیق» را بزنید.
3. برای آرشیو وضعیت فعلی سایت، «دانلود اسنپ‌شات زنده (JSON)» را بگیرید؛ همان فایل بعداً می‌تواند خط مبنای مقایسهٔ دو مقطع زمانی باشد.
