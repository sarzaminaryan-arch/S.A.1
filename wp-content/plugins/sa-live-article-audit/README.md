# افزونهٔ «ممیزی مقالات زنده — تطبیق با مخزن» (S.A.1)

افزونهٔ فقط‌خواندنی وردپرس برای **استخراج دقیق مقاله‌های منتشرشدهٔ سایت زنده** و
**تطبیق (reconciliation) آن‌ها با مخزن S.A.1**؛ همان کاری که مالک سایت لازم دارد
بداند: «چه چیزی از مخزن روی سایت رفته، چه چیزی فرق کرده، چه چیزی هنوز نرفته و
چه چیزی روی سایت هست ولی در مخزن نیست.»

راهنمای کامل نصب و خواندن گزارش: [`docs/live-article-audit-plugin.md`](../../docs/live-article-audit-plugin.md)

## خروجی‌ها

| خروجی | محتوا |
|---|---|
| اسنپ‌شات زنده JSON | متن کامل + هش‌ها، تیترها، لینک‌ها، تصاویر، طبقه‌بندی‌ها، متاها، FAQ، تصویر شاخص، روابط — برای هر مقالهٔ منتشرشده |
| اسنپ‌شات زنده CSV | خلاصهٔ جدولی همان اسنپ‌شات |
| گزارش تطبیق (پیشخوان + JSON/CSV) | یکسان / دارای اختلاف فیلدبه‌فیلد / فقط در سایت / فقط در مخزن / کلیدهای تکراری |

## منابع خط مبنای مخزن

1. **قالب فرزند** — `sa_ready_articles_data()` (دقیقاً دادهٔ ایمپورتر «مقالات آماده»؛ ۱۰۴ رکورد: ۶۷ راهنما + ۳۷ دیدنی/شهرستان).
2. **اسنپ‌شات همراه ZIP** — `data/baseline.json` که در CI از `data/ready-articles.php` و `data/ready-guides.php` ساخته می‌شود (فایل تولیدی؛ در گیت کامیت نمی‌شود).
3. **بارگذاری JSON** — هر اسنپ‌شات قبلی همین افزونه یا فایل هم‌قالب.

## قواعد تطبیق

- کلید: `post_type:slug`؛ تطبیق فقط روی نوشته‌های **منتشرشده** انجام می‌شود.
- فیلدها: عنوان، چکیده، محتوا (هش نرمال HTML، بعد هش متن ساده)، متاهایی که در مخزن مقدار دارند، `sa_faq`، نامک ترم‌های هر طبقه‌بندی، نام فایل و alt تصویر شاخص، روابط `province`/`city`.
- شدت `info` (فقط HTML فرق دارد، جای‌نگهدار `{{…}}` در متن مخزن، فایل گالری پیدا نشد، حذف صریح تصویر شاخص) «اختلاف واقعی» حساب نمی‌شود.
- نوشتهٔ رمزدار: متن آن وارد اسنپ‌شات نمی‌شود (فقط فراداده و هش خام).

## امنیت و حریم

- فقط `manage_options` + نانس؛ بدون REST عمومی، بدون درخواست خارجی، بدون نوشتن در دیتابیس محتوایی.
- اسنپ‌شات شامل متن کامل مقاله‌هاست؛ فایل دانلودشده را مثل خروجی پشتیبان نگه دارید.

## توسعه

```bash
php wp-content/plugins/sa-live-article-audit/tests/test-compare.php   # تست مستقل موتور تطبیق
php tools/generate-live-article-audit-baseline.php                    # ساخت baseline.json (در CI)
python3 tools/build-live-article-audit-plugin.py                      # ساخت ZIP نصب
```

انتشار از workflow ‏`.github/workflows/release-live-article-audit-plugin.yml` انجام می‌شود و ZIP به GitHub Release می‌رود.
