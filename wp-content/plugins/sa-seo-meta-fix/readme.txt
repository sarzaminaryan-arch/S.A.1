افزونهٔ یک‌بارمصرف برای همگام‌سازی امن عنوان و متادیتای سئوی شش راهنمای مشخص.

== Description ==
هنگام فعال‌سازی، شش نوشته با نامک پیدا می‌شوند. فقط فیلدهایی تغییر می‌کنند که مقدار فعلی‌شان دقیقاً با مقدار مشاهده‌شده در ممیزی ۲۰۲۶-۱۱-۱۱ یکی باشد. پیش از نخستین تغییر، نسخهٔ پشتیبان مقادیر در تنظیمات وردپرس ذخیره می‌شود و از مسیر «ابزارها ← اصلاح متای سئو (یک‌باره)» گزارش و دکمهٔ بازگردانی در دسترس است.

این افزونه به متن، تصویر شاخص، FAQ، منابع، برچسب/دسته و تاریخ انتشار یا ویرایش نوشته دست نمی‌زند.

== Installation ==
1. فایل ZIP را در «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب کنید.
2. افزونه را فعال کنید؛ اصلاح نگهبان‌دار هنگام فعال‌سازی اجرا می‌شود.
3. گزارش را در «ابزارها ← اصلاح متای سئو (یک‌باره)» ببینید.
4. ممیزی مقالات زنده را دوباره اجرا کنید.
5. پس از اطمینان، افزونه را غیرفعال و حذف کنید.
