بستهٔ یکپارچهٔ درون‌ریز ۲۴ مقاله (۱۲ شهرستان ایلام + ۱۲ شهر/شهرستان بوشهر) برای قالب فرزند «سرزمین آریان» — همراه تصاویر شاخص وب‌پی؛ همه‌چیز پیش‌نویس می‌ماند.

== Description ==

این افزونه در یک بسته، دو استان را درون‌ریزی می‌کند:

**ایلام (۱۲ شهرستان):** ایلام، مهران، دهلران، ایوان، آبدانان، دره‌شهر، چرداول، بدره، ملکشاهی، چوار، هلیلان، سیروان

**بوشهر (۱۲ مقالهٔ شهر/شهرستان):** بندر بوشهر، برازجان، بندر گناوه، خورموج، بندر کنگان، بندر عسلویه، جم، اهرم، بندر دیر، بندر دیلم، شهرستان بوشهر، شهرستان دشتستان

برای هر دو استان:

* متن کامل مقاله (۹ بلوک)، جدول‌ها، ارجاع‌های بالانویس با لینک منبع
* پرسش‌های متداول (متا «sa_faq») و منابع (متا «sa_sources»)
* فیلدهای مدل داده: جمعیت، مختصات، دسترسی هوایی/ریلی/جاده‌ای، لینک گوگل‌مپ
* اسکیمای City+TouristDestination، sameAs و containedInPlace
* سئو (عنوان، توضیحات، کلیدواژه، اوپن‌گراف) + همگام‌سازی اختیاری Rank Math
* برچسب استان (province_tax) و فصل سفر (travel_season) + اتصال به برگهٔ مادر استان (sa_province_id)
* **تصویر شاخص وب‌پی** — ۲۴ تصویر (۱۲ + ۱۲) در `assets/counties/`؛ متن جانشین (ALT)، زیرنویس، عنوان و توضیح هر تصویر از بلوک ۲ مقاله‌ها می‌آید.

نکته‌های مهم:

* هیچ‌چیز منتشر نمی‌شود؛ همه‌ی نوشته‌ها پیش‌نویس می‌مانند.
* نوشته‌های منتشرشده‌ی موجود بدون اجازه‌ی صریح بازنویسی نمی‌شوند.
* تصویر شاخص موجود صفحه بدون گزینه‌ی صریح بازنویسی نمی‌شود (شناسه‌ی sha1 برای جلوگیری از تکرار).
* فقط بسته‌های با وضعیت «DRAFT ONLY» وارد می‌شوند (دروازه‌ی سردبیر).
* قالب فرزند «سرزمین آریان» باید فعال باشد (نوع نوشته‌ی «شهر» و رابطه‌ی استان).

== Installation ==

**روش ۱ — از پیشخوان وردپرس (توصیه‌شده):**

1. فایل zip را از مسیر «افزونه‌ها → افزودن → بارگذاری افزونه» بارگذاری کنید.
2. پس از نصب، «فعال کردن» را بزنید.
3. از منوی «درون‌ریزی شهرستان‌ها» استان/شهرستان‌های موردنظر را انتخاب و درون‌ریزی کنید (دو زیرمنو: ایلام و بوشهر).

**روش ۲ — نصب دستی (اگر وردپرس بارگذاری را نپذیرفت):**

1. فایل zip را روی رایانه باز کنید؛ باید یک پوشه به نام «sa-city-importer-ilam-bushehr» ببینید که فایل اصلی افزونه در ریشهٔ همان پوشه است.
2. همین پوشه را در مسیر «wp-content/plugins/» سایت آپلود کنید (با FTP یا مدیریت فایل هاست).
3. از «افزونه‌ها» فعالش کنید.

با WP-CLI:

* `wp sa-city-import ilam`
* `wp sa-city-import bushehr`

== Frequently Asked Questions ==

= آیا چیزی منتشر می‌شود؟ =
خیر. همه‌ی نوشته‌ها پیش‌نویس ساخته می‌شوند و انتشار با سردبیر است.

= تصویر شاخص چگونه بارگذاری می‌شود؟ =
همراه هر صفحه، فایل webp همان شهر/شهرستان از پوشه‌ی assets/counties افزونه به کتابخانه‌ی رسانه منتقل و به‌عنوان تصویر شاخص تنظیم می‌شود؛ برای هر ۲۴ مقاله (ایلام ۱۲ + بوشهر ۱۲) تصویر موجود است.

= اگر پیش‌نویس قبلی وجود داشته باشد؟ =
با گزینه‌ی «به‌روزرسانی پیش‌نویس‌های موجود» همان پیش‌نویس به‌روزرسانی می‌شود.

= اگر افزونهٔ استانی جداگانهٔ دیگری فعال باشد؟ =
هستهٔ مشترک نسخهٔ ۱.۱.۱ است و بین افزونه‌ها فقط یک‌بار بار می‌شود؛ فعال‌بودن همزمان بستهٔ یکپارچه و بسته‌های استانی مشکلی ایجاد نمی‌کند، اما برای پرهیز از درون‌ریزی تکراری بهتر است فقط یکی فعال بماند.

= نامک‌ها چه وضعیتی دارند؟ =
نامک‌ها همان مقادیر ثبت‌شده در بستهٔ داده هستند.
ایلام: ilam-city، mehran، dehloran، eyvan، abdanan، darreh-shahr، chardavol، badreh، malekshahi، chavar، halilan، sirvan.
بوشهر: bushehr-city، borazjan، ganaveh، khormoj، kangan، asaluyeh، jam، ahram، deyr، deylam، bushehr-county، dashtestan.
این نامک‌ها با فهرست توافق‌شدهٔ دستهٔ b01 و سند docs/site-url-structure.md یکسان‌اند.
