# Iran Audit Dashboard

**نسخهٔ پیش‌نمایش:** `0.1.0` — بستهٔ قابل نصب برای ارزیابی دستی در محیط آزمایشی؛ تأیید تولیدی ندارد.

داشبورد فارسی/RTL برای نمایش وضعیت، گزارش‌ها، صف، قواعد، شکاف پوشش و ادعاهای نیازمند بررسی انسانی است. این افزونه فقط از REST API نسخهٔ `1.1` موتور استفاده می‌کند؛ هیچ اتصال مستقیمی به دیتابیس یا جدول‌های Engine ندارد.

- به `iran-audit-engine` فعال، nonce وردپرس و capability `iaa_view` نیاز دارد.
- ممیزی و تأیید/رد ادعا به `iaa_run` نیاز دارد.
- محتوای API با `textContent` به DOM اضافه می‌شود؛ برای CSV از درخواست دارای nonce استفاده می‌شود.
- در نبود Engine یا ناسازگاری API، صفحه پیام فارسی نشان می‌دهد و خروجی داده را متوقف می‌کند.
- گزارش PDF یا سرویس بیرونی در این نسخه به کار گرفته نشده است.

این نسخه برای نصب دستی و ارزیابی در محیط آزمایشی بسته‌بندی شده است؛ WordPress واقعی یا Staging در این نوبت اجرا نشده و نسخه تأیید تولیدی ندارد. برای استقرار در سایت تولیدی، آزمون قراردادی/امنیتی و بازبینی جداگانه لازم است.
