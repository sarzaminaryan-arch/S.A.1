افزونهٔ یک‌بارمصرف برای بازگرداندن FAQ هشت راهنمایی که بدنه‌شان با مخزن هم‌جهت است ولی sa_faq زنده‌شان خالی است.

== Description ==
هنگام فعال‌سازی، هشت نوشته با نامک پیدا می‌شوند و فقط اگر متای sa_faq آن‌ها خالی باشد، FAQ مخزن (برگرفته از متن خود مقاله) نوشته می‌شود. FAQ غیرخالیِ موجود هرگز بازنویسی نمی‌شود. پیش از نخستین تغییر پشتیبان ذخیره می‌شود و گزارش/بازگردانی در «ابزارها ← بازگردانی FAQ (یک‌باره)» در دسترس است.

متن، عنوان، تصویر، منابع و سایر فیلدها تغییر نمی‌کنند.

== Installation ==
1. فایل ZIP را در «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب کنید.
2. افزونه را فعال کنید؛ بازگردانی هنگام فعال‌سازی اجرا می‌شود.
3. گزارش را در «ابزارها ← بازگردانی FAQ (یک‌باره)» ببینید.
4. ممیزی مقالات زنده را دوباره اجرا کنید.
5. پس از اطمینان، افزونه را غیرفعال و حذف کنید.
