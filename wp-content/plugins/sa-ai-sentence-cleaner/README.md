# افزونهٔ وردپرس «پاک‌سازی جمله‌های هوش مصنوعی»

افزونهٔ قابل نصب روی همان سایتی که قالب سرزمین آریان رویش است، برای اعمال
پاک‌سازی روی **مقاله‌های منتشرشدهٔ داخل وردپرس** (از جمله ۴۸۳ مقالهٔ شهر با
post type `city`)؛ جایی که ابزار خط فرمان `ai_cleaner` به فایل‌ها دسترسی ندارد.

## نصب

1. از GitHub Release با برچسب `ai-cleaner-plugin-v1.0.0` فایل
   `sa-ai-sentence-cleaner-1.0.0.zip` را بگیرید.
2. پیشخوان وردپرس ← **افزونه‌ها ← افزودن ← بارگذاری افزونه** ← انتخاب ZIP ← نصب و فعال‌سازی.
3. منوی تازهٔ **«پاک‌سازی AI»** در پیشخوان ظاهر می‌شود. قالب لازم نیست عوض شود.

## طرز کار (به همین ترتیب)

1. **اسکن و پاک‌سازی ← شروع اسکن جدید:** نوع محتوا را انتخاب کنید (پیش‌فرض `city`).
   اسکن دسته‌های ۲۰تایی جلو می‌رود؛ با دکمهٔ «ادامهٔ اسکن» دستهٔ بعد. اسکن هیچ‌چیز را حذف نمی‌کند.
2. گزارش را ببینید: جمله‌های `DELETE` (نامزد حذف)، `FLAG` (فقط گزارش) و تکراری‌ها
   با نام مقاله، الگو و متن کامل جمله. خروجی CSV هم هست.
3. حذف، سه راه دارد:
   - **حذف همهٔ جمله‌های DELETE** در صفحهٔ اسکن؛
   - **حذف جمله‌های انتخاب‌شده** با تیک‌زدن در جدول (انتخاب شما یعنی تأیید همان جمله)؛
   - **جمله‌های تکراری:** گروه‌هایی که عیناً در بیش از ۳ مقاله آمده‌اند. گروه دارای
     الگوی هوش مصنوعی با یک دکمه از **همهٔ** مقاله‌ها حذف می‌شود؛ گروه بدون الگو
     فقط با تیک و تأیید خودتان.
4. **پشتیبان‌ها:** قبل از اولین تغییر هر مقاله، متن کامل قبلی ذخیره می‌شود و با
   یک دکمه برمی‌گردد (revision خود وردپرس هم ساخته می‌شود).

## قانون‌های ایمنی

- واحد حذف «کل جمله» است؛ هیچ نوشته، تیتر (`<h1>` تا `<h6>`)، جدول، کد، تصویر،
  لینک یا منبع معتبری حذف نمی‌شود و متن تازه‌ای اضافه نمی‌شود.
- جملهٔ مشکوک فقط `FLAG` می‌شود. جملهٔ داخل متن لینک خودکار حذف نمی‌شود.
- بیش از ۲۰٪ حذف در یک مقاله ⇒ مقاله دست‌نخورده و «بررسی دستی» (در تنظیمات قابل تغییر، پیش‌فرض ۲۰٪).
- منبع صرفاً google.com/chatgpt.com حذف، `utm_source=chatgpt.com` از لینک پاک و
  شمارهٔ منابع و ارجاع‌های `[n]` مرتب می‌شود؛ منبع معتبر (fa.wikipedia.org، سایت‌های ‎.ir) هرگز حذف نمی‌شود.
- همهٔ عملیات فقط برای مدیر (`manage_options`) با nonce است و فقط `post_content`
  نوشته‌های منتشرشده عوض می‌شود؛ وضعیت، عنوان، نامک و متاها دست نمی‌خورند.
- الگوها در **تنظیمات و الگوها** به‌صورت JSON قابل ویرایش‌اند؛ الگوهای پیش‌فرض
  همان نمونه‌های پرامپت اول‌اند (`includes/patterns.php`).

## ساخت ZIP از سورس

```bash
python3 tools/build-ai-cleaner-plugin.py
# خروجی: /tmp/sa-ai-sentence-cleaner-1.0.0.zip (خارج از درخت مخزن، طبق سیاست مخزن)
```
