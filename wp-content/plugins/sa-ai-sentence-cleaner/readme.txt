اسکن مقاله‌های منتشرشده و حذف جمله‌های پیش‌نویس و ردپای هوش مصنوعی و جمله‌های تکراری بین مقاله‌ها، با پشتیبان و بازگردانی.

== Description ==
* فقط جمله حذف می‌شود؛ هیچ نوشته، تیتر، جدول، تصویر، لینک یا منبع معتبری حذف نمی‌شود.
* جمله‌های دارای الگوی DELETE، جمله‌های FLAG (فقط گزارش) و جمله‌های تکراری در بیش از ۳ مقاله جدا گزارش می‌شوند.
* جملهٔ تکراری دارای الگوی هوش مصنوعی از صفحهٔ «جمله‌های تکراری» با یک دکمه از همهٔ مقاله‌ها حذف می‌شود.
* جملهٔ تکراری بدون الگو فقط با انتخاب و تأیید صریح مدیر حذف می‌شود.
* اگر بیش از ۲۰٪ متن یک مقاله حذف شود، آن مقاله دست‌نخورده می‌ماند و «بررسی دستی» می‌خورد.
* قبل از هر تغییر پشتیبان گرفته می‌شود و از پیشخوان قابل بازگردانی است.

== Installation ==
1. فایل ZIP را در «افزونه‌ها ← افزودن ← بارگذاری افزونه» بارگذاری و فعال کنید.
2. از منوی «پاک‌سازی AI» اول اسکن را کامل کنید، گزارش را ببینید، بعد حذف را بزنید.
