# Iran Audit Engine

**نسخهٔ پیش‌نمایش:** `0.1.0` — بستهٔ قابل نصب برای ارزیابی دستی در محیط آزمایشی؛ تأیید تولیدی ندارد.

موتور مستقلِ خواندنی برای اجرای قواعد ساختار و SEO از مسیر REST نسخهٔ `1.1` است. قواعد بسته در `data/rules.json` نسخهٔ `2026.10.08-2` نگهداری می‌شوند. نسخهٔ بسته‌شده باید با قرارداد بین افزونه‌ها تطبیق داشته باشد.

## مرزهای داده و دسترسی

- محتوای نوشته‌ها فقط خوانده می‌شود؛ موتور نوشته، متا، taxonomy، تنظیمات SEO، کش یا جدول اصلی WordPress را تغییر نمی‌دهد.
- گزارش، issue، نتیجهٔ دسته، صف، ادعا و تنظیمات افزونه در جدول‌های اختصاصی با پسوند `iaa_*` نگهداری می‌شوند.
- صفحهٔ نگاشت پروفایل زیر **ابزارها ← تنظیمات موتور** است. CPT موجود `city` به‌طور خودکار به پروفایل قواعد `county` در API 1.1 وصل می‌شود؛ این فقط alias سازگاری است و موجودیت/CPT جداگانهٔ County ایجاد نمی‌کند. سایر نوع‌نوشته‌های مبهم بدون نگاشت می‌مانند.
- capabilityهای پیش‌فرض `iaa_view` و `iaa_run` برای Editor و بالاتر، و `iaa_manage` برای مدیر هستند؛ نقش‌ها در دیتابیس تغییر داده نمی‌شوند.
- تاریخ‌های machine-readable بر پایهٔ UTC/Gregorian هستند.

## وضعیت اجرا

- قواعد از JSON محلی اعتبارسنجی می‌شوند؛ JSON و داده‌های واژه‌نامه در زمان اجرا تغییر نمی‌کنند.
- صف از WP-Cron به‌صورت تکه‌ای کار می‌کند؛ هر تیک یک نوشته را پردازش می‌کند و Jobهای فعال برای هر نوشته idempotent هستند.
- دریافت HTML رندرشده خاموش است. فعال‌سازی آن فقط opt-in مدیر و پس از آزمون staging باشد؛ URL باید همان میزبان باشد و redirect دنبال نمی‌شود.
- بررسی لینک بیرونی، PageSpeed، AI، زمان‌بندی ممیزی شبانه، دیتاست تقسیمات کشوری و مجموعهٔ طلایی در این نسخه پیاده نشده‌اند. تنظیم ترجیح لینک بیرونی به‌تنهایی هیچ درخواست شبکه‌ای ایجاد نمی‌کند.
- به‌صورت پیش‌فرض ۱۰ گزارش آخر هر نوشته نگهداری می‌شود؛ مدیر می‌تواند عدد را بین ۱ تا ۱۰۰ تغییر دهد. پاک‌سازی فقط جدول‌های فرزند و گزارش قدیمی Engine را در همان محدوده لمس می‌کند.
- داده‌ها هنگام غیرفعال‌سازی یا حذف افزونه پاک نمی‌شوند.

## آزمون محلی

از ریشهٔ repository:

```sh
python3 wp-content/plugins/iran-audit-engine/tests/test_contract_smoke.py
node --check wp-content/plugins/iran-audit-dashboard/assets/dashboard.js
```

این smoke testها قرارداد فایل/قواعد و چند مرز ایمنی را بررسی می‌کنند؛ جایگزین آزمون واقعی WordPress، دیتابیس، REST، امنیت، staging یا Golden Set نیستند.
