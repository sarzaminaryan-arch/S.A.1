حذف ایمن یادداشت‌های تولیدی/فرایندی از متن منتشرشده، با پشتیبان، گزارش و بازگردانی.

== Description ==

افزونهٔ یک‌بارمصرف برای مرحلهٔ ۲ «برنامهٔ رفع مشکلات محتوا» (docs/live-site/content-remediation-roadmap.md).

* همان قواعد موتور مرجع `tools/wp-agent/content_fix.py` (پورت وفادارانه؛ با فیکسچرهای `tests/fixtures.json` سنجیده می‌شود).
* حذف جمله/بند یادداشتی، مورد فهرستی یادداشتی، جملهٔ تکراری درون‌صفحه، کوتاه‌سازی مورد خلاصه، پاک‌سازی جدول و تیتر خالی.
* هیچ متن تازه‌ای افزوده نمی‌شود؛ هیچ تیتر/جدول/تصویر/لینک/منبع معتبری حذف نمی‌شود.
* نگهبان‌ها: سقف افت حجم ۸٪ (بیش از آن ⇒ صفحه دست نمی‌خورد و «نیازمند بازنویسی» گزارش می‌شود)، بررسی واژه‌های ممنوع روی خروجی، پشتیبان کامل پیش از هر نوشتن، بازگردانی یک‌کلیکی، idempotent.
* فعال‌سازی فقط «پیش‌نمایش» می‌سازد؛ اعمال با دکمهٔ «اعمال اصلاح» (فرمان صریح مالک) انجام می‌شود.

== Installation ==

1. پوشهٔ `sa-editorial-fix` را در `wp-content/plugins/` بگذارید یا ZIP را از پیشخوان نصب کنید.
2. افزونه را فعال کنید (پیش‌نمایش خودکار ساخته می‌شود).
3. ابزارها ← «ترمیم یک‌بارهٔ یادداشت‌ها» ← «اعمال اصلاح».
4. گزارش را بررسی کنید؛ در صورت نیاز «بازگردانی آخرین اجرا».
5. پس از راستی‌آزمایی، «پایان و غیرفعال‌سازی» و حذف افزونه.
