# قوانین اجرایی پروژه S.A.1 (آخرین نسخه جاری)

1. ممنوعیت آنالیز مجدد: هیچ ایجنتی حق ندارد کل پروژه را از صفر آنالیز کند.

قانون تست‌ها و CI: ایجنت در محیط محلی (Local) حق ندارد تست‌هایی را که در `STATUS.md` سبز ثبت شده‌اند دوباره اجرا کند تا زمان و توکن تلف نشود. اما تمام Workflowهای CI در GitHub Actions باید به صورت کامل و ۱۰۰٪ سبز (Pass) شوند. هیچ ادغامی بدون CI سبز معتبر نیست.

2. محدودیتهای سرور و بکاپ: گرفتن بکاپ‌های سنگین، دانلود/آپلود حجم بالا و پر کردن رم/دیسک سرور ممنوع است. تمام عملیات‌ها باید سبک و ایزوله باشند.

3. ممنوعیت تغییرنام سیستمی: تغییر نام فایل‌های اصلی (`style.css` ،`functions.php` ،`README.md` ،`CHANGELOG.md` یا workflowها) به `vN` ممنوع است. پسوند `vN` فقط برای اسناد محتوایی است.

4. دستکاری فایل‌ها: هیچ فایلی بدون دستور مستقیم حذف یا منتقل نمی‌شود.

5. به روزرسانی قوانین: هرگاه قانون جدیدی وضع شد، قانون قبلی کاملاً پاک شده و قانون جدید جایگزین می‌شود (بدون ثبت تاریخچه در این فایل).

6. روش کار (TDD): تست را مشخص کن -> کد را اصلاح کن -> تست را سبز کن -> فایل‌های `.agent/` را آپدیت کن -> Commit بزن.
