# drafts/ — پیش‌نویس‌های بیرونی در انتظار فیلتر ویراستار

این پوشه **صف ورودی** مقاله‌های استان است: خروجی مدل‌های هوش مصنوعی بیرونی که مالک با
`content-templates/province-external-prompt.md` تولید می‌کند و هنوز از فیلتر ویراستار سرزمین آریان نگذشته‌اند.

- `drafts/{slug}.md` — پیش‌نویس در قرارداد ۹ بلوکی (اگر خروجی مدل خراب/صادرشده باشد، اینجا نسخه‌ی بازسازی‌شده می‌نشیند).
- `drafts/raw/` — فایل خام همان‌طور که رسیده (برای ردگیری؛ پس از فیلتر هم نگه داشته می‌شود).

## چه چیزی «پیش‌نویس» را «نوشته‌شده» می‌کند

فایل وقتی به `content/provinces/{slug}.md` منتقل می‌شود که فیلتر ویراستار این‌ها را برقرار کرده باشد
(همان سنجه‌هایی که `province_status.py` می‌شمارد):

| سنجه | حداقل |
|---|---|
| بلوک‌ها | هر ۹ بلوک + پیوست الف |
| واژه‌ی متن (بلوک ۳ بدون جدول/ارجاع/نشان) | ≥ ۴٬۰۰۰ (سقف ۷٬۰۰۰) |
| FAQ | ≥ ۱۰ (هدف ۱۲؛ پاسخ ۴۰–۹۰ واژه) |
| منابع (بلوک ۵) | ≥ ۵ ردیف، هر ردیف یک URL، هدف ۲۵–۴۰ |
| ارجاع‌های بالانویس | `<sup>[n](URL)</sup>` منطبق با ردیف n بلوک ۵؛ `seo_audit.py` = PASS |
| بخش‌های کیفی (v1.1، گروه الف) | هیچ‌کدام با «گزارش نشده» رد نشده؛ منابع `[میراث]`/`[محلی]`/`[سفرنامه]` جست‌وجو شده |
| نشان‌ها | هدف ≤ ۳۰؛ روی گزاره‌ی توصیفیِ منبع‌دار نشان نمی‌ماند |
| افق زمانی | بدون «امسال/اخیراً/هم‌اکنون»؛ داده‌ی فرّار با تاریخ نقل؛ سرصفحه‌ی «افق زمانی: تا مهر ۱۴۰۵ / سپتامبر ۲۰۲۶» |

افزونه‌های درون‌ریز (`build_import_package.py`) فقط `content/provinces/{slug}.md` را می‌خوانند؛ چیزی از این پوشه به وردپرس نمی‌رود.

## وضعیت فعلی

`python3 content-templates/tools/province_status.py` را اجرا کنید؛ ردیف‌های 🟡 همین پوشه‌اند و ستون «وضعیت» می‌گوید هر کدام چه کم دارد.
