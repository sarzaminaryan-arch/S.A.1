# Sarzamin Aryan — Priority County Fix Importer v1.0.4

این بسته برای تکمیل ۵ مقاله شهرستانی ساخته شده است:

1. شهرستان ترکمانچای — استان آذربایجان شرقی
2. شهرستان فردوس — استان خراسان جنوبی
3. شهرستان سملقان — استان خراسان شمالی، مرکز: آشخانه
4. شهرستان مانه — استان خراسان شمالی، مرکز: پیش‌قلعه
5. شهرستان بام و صفی‌آباد — استان خراسان شمالی، مرکز: صفی‌آباد

## جمع‌بندی اصلاح خراسان شمالی

- «شهرستان مانه و سملقان» نام قدیمی/پیشین است، نه یک شهرستان فعلی جدا کنار مانه و سملقان.
- «آشخانه» مرکز شهرستان سملقان است.
- «شهرستان مانه» جداست و مرکز آن پیش‌قلعه است.
- اگر هفت مقاله خراسان شمالی آماده است و تحلیل سه مورد خالی نشان می‌دهد، سه مورد تکمیلی معمولاً همین‌ها هستند: سملقان، مانه، بام و صفی‌آباد.

## روش اجرا

1. فایل ZIP را از GitHub دانلود و در وردپرس نصب کنید.
2. افزونه را فعال کنید.
3. در صفحه افزونه‌ها روی لینک **اجرای ایمپورت مستقیم** کلیک کنید.
4. اگر صفحه ابزارها باز شد، می‌توانید دکمه **اجرای ایمپورت / به‌روزرسانی** را هم بزنید.

## نکته‌های فنی

- نوشته‌های جدید با وضعیت Draft ساخته می‌شوند؛ نوشته‌های موجود با وضعیت قبلی به‌روزرسانی می‌شوند.
- متاهای Rank Math پر می‌شوند.
- تصویر شاخص عمداً دست‌نخورده می‌ماند.
- نامک‌های قدیمی/جایگزین مثل `maneh-and-samalqan` و `maneh-ashkhaneh` فقط اگر از قبل در سایت وجود داشته باشند تکمیل یا به رکورد درست منتقل می‌شوند؛ افزونه رکورد قدیمی جدید نمی‌سازد.
