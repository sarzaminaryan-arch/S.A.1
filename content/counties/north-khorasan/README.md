# بسته اصلاحی شهرستان‌های خراسان شمالی

این پوشه فعلاً بسته کامل استان نیست؛ سه مقاله تکمیلی برای رفع اختلاف تقسیمات جدید و رکوردهای خالی وردپرس است.

## نتیجه بررسی

- آشخانه مرکز **شهرستان سملقان** است، نه مرکز شهرستان مانه.
- **شهرستان مانه** از سال ۱۴۰۲ جداست و مرکز آن **پیش‌قلعه** است.
- **مانه و سملقان** نام پیشین/قدیمی است و نباید به‌عنوان شهرستان فعلی جداگانه کنار مانه و سملقان نگهداری شود.
- مورد سومِ خالی در خراسان شمالی معمولاً **شهرستان بام و صفی‌آباد** است که در سال ۱۴۰۱ از اسفراین جدا شد.

## مقاله‌های داخل این پوشه

- `08-samalqan.md` — شهرستان سملقان، مرکز آشخانه
- `09-maneh.md` — شهرستان مانه، مرکز پیش‌قلعه
- `10-bam-and-safiabad.md` — شهرستان بام و صفی‌آباد، مرکز صفی‌آباد
