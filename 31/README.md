- **(c) بخش پایانی مشارکت مردمی:** به هر ۱۰ مقاله، H2 پایانی «از مردم عزیز استان …، یک درخواست داریم» با ایمیل `Mail@sarzaminaryan.ir` افزوده شد (ساختار ۳۱ H2).
