[LEARN-20261127-01] تفکیک «صفحهٔ پیش‌فرض cPanel» از «سایت واقعی» و از «فیلتر شبکه»

· دسته: Ops / Hosting
· محتوا: وقتی سایت بالا نمی‌آید، سه حالت کاملاً متفاوت را باید از هم جدا کرد: (۱) دامنه resolve می‌شود ولی Apache صفحهٔ پیش‌فرض می‌دهد (`Default Web Site Page` یا `defaultwebpage.cgi`) → مشکل vhost/Document Root، نه وردپرس؛ (۲) TCP باز است ولی TLS با SNI همان دامنه EOF می‌شود → برای دامنه گواهی/vhost TLS ساخته نشده (AutoSSL اجرا نشده)؛ (۳) پاسخ خالی/بسته در همهٔ درگاه‌ها برای همهٔ دامنه‌های یک کشور → فیلتر شبکهٔ سندباکس، نه سایت. ابزار `tools/ops/site_health.py` هر سه را با یک فرمان و کد خروج ۰/۱ گزارش می‌کند. سنجش از دو مسیر مستقل (curl سندباکس + fetcher بیرونی) انجام شود، چون سندباکس دامنه‌های ایرانی را فیلتر می‌کند.
· شرایط کاربرد: هر گزارش «سایت قطع شده»، هر تغییر دامنه/هاست، هر بار که پل ایجنت (`wp-agent`) با `network error` متوقف می‌شود.
· منبع/تجربه: حادثهٔ ۲۰۲۶-۱۱-۲۷ (Addon Domain شدن `sarzaminaryan.ir`)؛ ایمیل (MX/SPF) سالم ولی وب قطع بود که ثابت می‌کند مشکل فقط لایهٔ وب است.

[LEARN-20261122-01] اولویت سلکتور و پوشش دوگانه برای کامپوننت‌های داخل `.sa-2026-prose`

· دسته: CSS
· محتوا: در طراحی ۱۴۰۵، کلاس `.sa-2026-prose a` به‌صورت پیش‌فرض خط زیر (`text-decoration: underline`) و رنگ لینک متنی اعمال می‌کند. برای هر کارت، دکمه یا قرص لینک داخل مقاله باید سلکتور دوگانه با اختصاصیت حداقل `(0,2,1)` نوشت تا هم درون `.sa-2026-prose` و هم خارج از آن بدون `!important` کار کند:
```css
.sa-2026-prose .sa-source-boxes a.sa-source-box,
.sa-source-boxes a.sa-source-box {
	text-decoration: none;
}
```
· شرایط کاربرد: هر بار که المان `<a>` داخل بدنهٔ مقاله (به‌جای متن ساده) به‌شکل دکمه، کارت یا pill رندر می‌شود.
· منبع/تجربه: پیاده‌سازی باکس منابع لرستان در نسخهٔ `2.24.15` (`assets/css/child.css`).
