# ai_cleaner — پاک‌سازی جمله‌های هوش مصنوعی از مقاله‌های شهرستان (city)

ابزار خط فرمان Python 3.11+ (بدون هیچ وابستگی بیرونی) که **فقط جمله‌های**
پیش‌نویس و ردپای هوش مصنوعی را از مقاله‌ها حذف می‌کند.

## قانون اصلی (تغییرناپذیر)

- فقط «جمله» حذف می‌شود؛ هیچ مقاله، فایل، پوشه، تیتر، جدول، تصویر، لینک یا منبع معتبری حذف نمی‌شود.
- هیچ متن تازه‌ای اضافه نمی‌شود و هیچ عدد، نام یا واقعیتی تغییر نمی‌کند.
- شک داری جمله‌ای هوش مصنوعی است یا نه؟ حذفش نکن؛ فقط با سطح `FLAG` در گزارش بیاور.
- اگر بیش از ۲۰٪ متن یک مقاله قرار باشد حذف شود، مقاله دست نمی‌خورد و در گزارش
  با برچسب «بررسی دستی» (`manual-review`) می‌آید.
- front matter، بلوک کد، تگ HTML، آدرس لینک و نام فایل هرگز تغییر نمی‌کند.
- مقالهٔ بدون الگو بایت‌به‌بایت یکسان می‌ماند و ابزار idempotent است.

## ورودی

- مخزن: `sarzaminaryan-arch/S.A.1`
- پوشهٔ مقاله‌ها: `city/` (۴۸۳ مقالهٔ شهرستان؛ در وردپرس post type شهر است).
  در چک‌اوت فعلی، فایل‌های .md این مقاله‌ها هنوز در مخزن نیستند و فقط رجیستری
  ۴۸۳ شهرستان (`wp-content/themes/sarzaminaryan-child/data/counties.php`) هست؛
  به همین دلیل `scan` در نبودِ `city/` روی کل مخزن گزارش اطلاعاتی می‌سازد و
  `next` بدون فایل مقاله، دسته‌ای اجرا نمی‌کند.
- فایل‌های `.md` و `.html` و `.txt` به‌صورت بازگشتی، مرتب الفبایی بر اساس مسیر.
- توکن گیت‌هاب فقط از `.env` (کلید `GITHUB_TOKEN`) خوانده می‌شود؛ `.env` در `.gitignore` است.

## دستورها

```bash
python -m ai_cleaner scan                      # فقط گزارش (reports/scan/)، بدون هیچ تغییری
python -m ai_cleaner status                    # دسته‌های انجام‌شده و باقی‌مانده
python -m ai_cleaner next                      # فقط یک دستهٔ ۲۰تایی، بعد توقف کامل
python -m ai_cleaner revert --batch 1          # برگرداندن دستهٔ ۱ با git revert
```

گزینه‌های مشترک: `--root .`، `--content-dir city`، `--patterns PATH`، `--batch-size 20`
و برای `next`: `--base main` و `--local-only` (فقط اصلاح و گزارش محلی، بدون هیچ عملیات گیت).

## اجرای نوبتی و انتشار

- مقاله‌ها الفبایی به دسته‌های ۲۰تایی تقسیم می‌شوند؛ پیشرفت در `progress.json`
  (در `.gitignore`) می‌ماند تا قطع‌شدن کار از همان‌جا ادامه پیدا کند.
- بعد از هر دسته: شاخهٔ `cleanup/batch-NNN` از `main`، کامیت فقط فایل‌های همان دسته
  با پیام «پاک‌سازی جمله‌های هوش مصنوعی: دستهٔ NNN (X مقاله، Y جمله حذف شد)»،
  push، یک Pull Request با جدول تغییرات (فایل، جملهٔ حذف‌شده، id الگو) و یک
  Release/Tag به اسم `cleanup-vNNN` با zip فقط فایل‌های تغییرکرده (با همان مسیر پوشه‌ها).
- **merge هرگز انجام نمی‌شود**؛ بررسی و merge با مالک است. force push هرگز.
- گزارش هر دسته در `reports/batch-NNN/` : `report.csv`
  (فایل، عنوان، خط، id الگو، سطح، جملهٔ کامل، اقدام) و `report.html` راست‌به‌چپ
  با diff رنگی قبل و بعد.

## الگوها

همهٔ الگوها در `patterns.yaml` کنار همین بسته‌اند تا مالک اضافه/کم کند:
هر الگو `id`، `regex`، سطح (`DELETE` حذف خودکار | `FLAG` فقط گزارش) و توضیح دارد.
تطبیق روی متن نرمال‌شده انجام می‌شود (ی/ک عربی، نیم‌فاصله/فاصله/نبود فاصله، اعراب
و کشیده، و رقم‌های فارسی/عربی/انگلیسی یکسان‌اند) ولی متن خروجی همیشه متن اصلی است.

منابع: منبعی که *فقط* google.com یا chatgpt.com یا chat.openai.com باشد حذف
می‌شود، `utm_source=chatgpt.com` از لینک‌ها پاک می‌شود (خود لینک می‌ماند) و بعد
شماره‌گذاری منابع و ارجاع‌های `[n]` داخل متن مرتب می‌شود. منبع معتبر
(مثل fa.wikipedia.org یا سایت‌های .ir) هرگز حذف نمی‌شود.
