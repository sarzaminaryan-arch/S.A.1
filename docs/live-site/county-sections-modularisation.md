# مدولارسازی سکشن‌های صفحهٔ شهرستان — نسخهٔ ۲.۲۲.۱۴۶

ممیزی فقط‌خواندنی + طرح مدولار + ابزار ویرایش دسته‌جمعی + آزمون ده شهرستان.
هیچ نوشته‌ای در دیتابیس بازنویسی نشد؛ تغییر، تغییرِ **قالب** است.

## ۱) ممیزی: سکشن‌های فعلی صفحهٔ شهرستان

پیش از این کار، صفحهٔ شهرستان از **سیزده بلوک** ساخته می‌شد که در **دو فایل** پخش بودند:
`template-parts/entity/single.php` (شاخهٔ `city`) و
`template-parts/entity/county-profile.php` که **۶۸۶ خط** بود و شناسنامه، نکته‌های
کوتاه و «تجربهٔ مسافرها» را در یک فایل به هم چسبانده بود.

| # | سکشن | محل پیشین | گروه |
|---|------|-----------|------|
| ۱ | تصویر شاخص شهرستان | `single.php` | ساختاری |
| ۲ | فهرست مطالب (آکاردئون بسته) | `single.php` (از بدنه گرفته می‌شد) | ساختاری |
| ۳ | شناسنامه (کادرهای ۰۱…۱۳) | `county-profile.php` (خط ۴۶۱–۵۶۰) | ساختاری |
| ۴ | نکته‌های کوتاه (قدمت/صنعت/کشاورزی) | `county-profile.php` (۵۶۱–۵۸۵) | محتوایی |
| ۵ | تجربهٔ مسافرها | `county-profile.php` (۵۸۶–۶۸۶) | محتوایی |
| ۶ | بدنهٔ مقاله (`sa:sec:*`) | `single.php` | محتوایی |
| ۷ | سوالات متداول | `entity/faq.php` | محتوایی |
| ۸ | گالری تصاویر | `single.php` → `sa_photo_strip()` | ساختاری |
| ۹ | امتیاز کاربران | `single.php` → `CC_UI` | ساختاری |
| ۱۰ | منابع + هم‌استانی‌ها | `single.php` → `sa_sources_section()` | محتوایی |
| ۱۱ | مشارکت مردمی | `single.php` → `CC_UI` | ساختاری |
| ۱۲ | نوشته‌های مرتبط | `single.php` | ساختاری |
| ۱۳ | ناوبری قبلی/بعدی | `single.php` | ساختاری |

یعنی وضعیت پیشین **نیمه‌جدا** بود: هفت بخش از قبل تابع/فایل جدا داشتند، ولی
**هیچ‌جا نمی‌شد دید ترتیب کل صفحه چیست** و سه بخش سنگین در یک فایل ۶۸۶ خطی
قفل بودند.

## ۲) طرح نهایی رجیستری (یک فایل، یک آرایه)

`inc/county-sections.php` تنها منبع حقیقت است. هر سکشن:

```php
'sa-county-gallery' => array(
    'label'  => 'گالری تصاویر شهرستان',
    'group'  => 'structure',       // structure | content
    'render' => 'sa_county_photos_html',
    'when'   => 'has_photos',      // always | has_facts | has_insights | has_faq | has_photos | cc_ui
    'order'  => 90,                // اختیاری؛ کوچک‌تر = بالاتر
    'enabled'=> true,              // اختیاری
),
```

قالب (`single.php`) فقط `sa_county_render_sections( $sa_id )` را صدا می‌زند.
**تغییر ترتیب / خاموش‌کردن / افزودن سکشن = یک سطر در همین فایل** و هیچ اثری روی
۴۸۴ نوشتهٔ `city` ندارد (رندر زمان‌محور است، نه ذخیره‌شده).
فیلتر `sa_county_sections` هم برای افزودن سکشن از قالب فرزند/افزونه هست.

فایل‌ها:

```
inc/county-sections.php          رجیستری (کلید، گروه، order، enabled، when)
inc/county-sections-loader.php   render* functions + کش هم‌استانی
template-parts/county/section-{cover,toc,identity,notes,field-notes,body,faq,
                               photos,rating,sources,contrib,related,nav}.php
template-parts/entity/county-profile.php   پوستهٔ سازگاری ۲۹ خطی (از ۶۸۶ خط)
```

## ۳) مکانیزم ویرایش دسته‌جمعی

- **ساختاری:** تغییر فایل سکشن = اثر فوری روی همهٔ صفحه‌ها. کاری لازم نیست.
- **محتوایی:** `sections` (زیردستور جدید `wp_agent.py`) یک سکشن نشانه‌دار را
  جایگزین می‌کند و بقیهٔ بدنه را دست‌نخورده می‌گذارد، با
  `expected_modified_gmt` (جلوگیری از بازنویسی تغییر تازه) و همان گاردهای مسیر
  نوشتن (`fa_lint`، `check_county_shape`، `check_banned`) و نسخهٔ محلی پیش از نوشتن.
- `tools/wp-agent/sections_bulk.py`: `plan → build (با گارد) → apply (دستهٔ ۲۵–۳۰ تایی) → verify`.
  سقف دسته ۳۰ است و بیشتر را رد می‌کند (قید حجم سرور، همان دستور شما).

## ۴) سرعت

- دادهٔ مشترک صفحه یک‌بار در `sa_county_sections_context()` جمع و memo می‌شود؛
  ۱۳ سکشن هیچ کوئری تکراری نمی‌زنند.
- لینک‌سازی هم‌استانی از `sa_county_siblings_cached()` (transient یک‌ساعته،
  پاک‌شده با هر ذخیره/حذف `city`) — قبلاً هر شهرستانِ هم‌استان یک
  `get_page_by_path()` جدا می‌زد.
- گالری همان lazy-load قبلی؛ هیچ تصویری eager نشد.

## ۵) تست و نتیجه

- گارد جدید `tests/test-county-sections.php` (در `build-gates`): کلیدها،
  یکتایی، وجود تابع رندر و فایل، **قفل ترتیب پیش‌فرض = چیدمان قبلی**،
  کارکرد `order`/`enabled`/`when`.
- گیت‌های انتشار هم‌راستا شدند (`test-featured-images`، `test-sources-last`،
  `test-county-insights`، `test-county-profile`، `test-county-map`،
  `test-county-media`): همان ادعاها، روی محل جدید کد.
- **رگرسیون میدانی ده شهرستان** (تهران، مشهد، اصفهان، تبریز، کرج، شیراز، اهواز،
  قم، کرمانشاه، رشت) با مقایسهٔ شمارنده‌های پروب در برابر پایهٔ ۲.۲۲.۱۲۸:
  **۰ تفاوت** پس از رفع یک رگرسیون واقعی (زیر).

### رگرسیونی که آزمون پیدا کرد و رفع شد

در نسخهٔ اولِ مدولارسازی، سکشن «منابع» فهرست «شهرهای هم‌استانی» را خودش چاپ
می‌کرد، در حالی که `sa_sources_section()` از ۲.۲۲.۸۶ همان را چاپ می‌کند →
آکاردئون دوبار (۳ به‌جای ۲) روی تهران و مشهد. در ۲.۲۲.۱۴۶ رفع شد و دو گارد
گذاشته شد که برنگردد.

## نسخه و وضعیت

- نسخه: **۲.۲۲.۱۴۶** — منتشرشده و روی سایت زنده نصب و سالم.
- آزمون سکشن روی ده شهرستان: **۱۰/۱۰** پذیرفته (آزمون خشک؛ هیچ نوشته‌ای
  تغییر نکرد). گسترش به ۴۵۴ شهرستان دیگر **انجام نشده** و منتظر تأیید شماست.
