# شواهد صفحهٔ اصفهان (پست ۳۴۲۹)

| گزارهٔ متن | منبع ۱ | منبع ۲ |
|---|---|---|
| میدان نقش جهان با چهار بنای صفوی و ثبت جهانی ۱۱۵ | یونسکو، پروندهٔ ۱۱۵ (شرح رسمی: مسجد شاه، مسجد شیخ لطف‌الله، سرسرای قیصریه، کاخ تیموری) | گزارش‌های داخلی: ثبت ۱۳۵۸/۱۹۷۹ با شمارهٔ ۱۱۵، ثبت ملی ۱۰۲ |
| جمعیت ۲٬۱۳۰٬۹۷۰ و تفکیک شهری/روستایی | مرکز آمار، سرشماری ۱۳۹۵ | صفحهٔ فرمانداری اصفهان (همان عدد) |
| مساحت ۱٬۶۷۲ کیلومتر مربع و یک بخش/۷ دهستان/۴ شهر | فرمانداری اصفهان | جدول تقسیمات ۱۳۹۵ (کرارج، براآن شمالی/جنوبی، قهاب شمالی/جنوبی، جی، محمودآباد) |
| تفکیک ۱۴۰۰ و ایجاد چهار شهرستان تازه | مصوبهٔ هیئت وزیران ۱۴۰۰/۴/۲۷ (بخش‌های کوهپایه، بن‌رود، جرقویه، جلگه) | بازتاب در متن فعلی صفحه و منابع تقسیمات |
| خشکی بستر زاینده‌رود در شهر | ایرنا/دنیای اقتصاد: «بارندگی هست، اما آبی وارد رودخانه نمی‌شود» (۰۶ دی ۱۴۰۴) | ایرنا/تابناک: «اثری از جاری بودن رودخانه کنار پل‌های تاریخی نیست»؛ گزارش وضعیت مهر ۱۴۰۵: بستر زیر سی‌وسه‌پل و خواجو خشک |
| فرونشست به‌عنوان بحران اصلی شهر | مهر ۶۵۵۲۱۱۲ (۱۴ مرداد ۱۴۰۴): مدیرکل محیط‌زیست — «فرونشست بزرگ‌ترین چالش استان» | مهر: رسیدن فرونشست به پل‌های تاریخی و مسجد جامع |
| مترو: خط یک ۲۱ کیلومتر، ۲۰ ایستگاه، ~۱۲۰ هزار مسافر روزانه | ایمنا ۱۰۱۷۳۵۹ (آذر ۱۴۰۵) | ایمنا/جام‌جم: همان ۲۱ کیلومتر و ۲۰ ایستگاه؛ ایرنا/ریل‌نیوز: ۲۰٫۷ کیلومتر قدس–صفه |
| کوه صفه: مسیر مارپیچ، تله‌کابین، ورود رایگان، هشدار صعود در هوای ناپایدار | ایمنا ۱۰۱۷۹۹۵ (۱۵ آبان ۱۴۰۵): هشدار مسئول پارک | صفحه‌های بازدید صفه: ورود رایگان، تفریحات و پارکینگ جدا، ساعت ۶ تا ۲۴ |
| ناژوان: پارک جنگلی غرب شهر، ورود رایگان، باغ پرندگان/آکواریوم/خزندگان با بلیت جدا | ایمنا ۱۰۱۱۶۴۷ و ۳۴۹۵۳۴ (مراکز گردشگری ناژوان، ساعات و بلیت) | صفحه‌های بازدید ناژوان: ورود رایگان، بخش‌ها بلیت جدا |
| بریان/بریانی مشهورترین غذای محلی | ایمنا ۲۴۳۸۱۲ (روایت تاریخ بریان) | مهر ۴۲۶۰۰۱۴ (بریانی معروف‌ترین غذای محلی اصفهان) |
| بازار قیصریه/بازار بزرگ در برابر مراکز مدرن | ایمنا ۷۳۷۳۰۲ (بازار و مرکز خرید اصفهان) | جدول‌های مراکز خرید: سیتی‌سنتر، بازار قیصریه |
