# متن ویکی‌پدیا — فقط برای خواندن

این‌جا متن صفحهٔ ویکی‌پدیای شهرستانی که می‌نویسیم ذخیره می‌شود، تا گارد یونیک بودن
(`tools/wp-agent/replace_src/wiki_overlap.py`) بتواند بی‌شبکه هم بسنجد.

قاعده (دستور مالک، ۲۶ آبان ۱۴۰۵):
1. ویکی‌پدیا **حداکثر یک خط** در `sa_sources`، و **فقط** برای جمعیت/مساحت، آن هم وقتی منبع
   رسمی نیست.
2. متن ویکی خوانده می‌شود تا داده و ترتیب تقسیمات درست باشد؛ **جمله‌ای از آن کپی نمی‌شود**.
3. همهٔ مطالب جز همان عدد، برداشت شخصی و بازنویسی است تا مقاله برای گوگل **یونیک** باشد.

اجرا:
```
python3 tools/wp-agent/replace_src/wiki_overlap.py tools/wp-agent/outbox/<dir> \
    --url https://fa.wikipedia.org/wiki/شهرستان_<name> --wiki-file docs/live-site/briefs/wiki/<slug>.txt
```
