# سامانه گالری آلبومی استان‌ها و بهینه‌ساز تصویر

نسخه معرفی: `sarzaminaryan-child` v2.11.7

## هدف

برای هر صفحه استان یک گالری مینیمال ساخته می‌شود که به تعداد شهرستان‌های همان استان، آلبوم آماده دارد. آلبوم‌ها دستی ساخته نمی‌شوند؛ از رابطه رسمی استان ↔ شهرستان قالب خوانده می‌شوند و حتی اگر هنوز تصویری نداشته باشند، کارت آلبوم آماده نمایش داده می‌شود.

## ساختار نمایش

- صفحه استان: «گالری تصاویر استان …» با کارت‌های آلبوم شهرستان‌ها.
- صفحه شهرستان: آلبوم همان شهرستان.
- رنگ‌بندی: سفید، آبی ناوی، طلایی تیره مطابق پالت سایت.
- نوار بالایی آلبوم‌ها شامل نقطه چشمک‌زن و مسیر آلبوم است تا کاربر متوجه بخش تصاویر شود.
- بازشدن آلبوم با لایت‌باکس داخلی و بدون کتابخانه خارجی انجام می‌شود.
- در موبایل، حرکت اصلی با لمس/سوایپ است؛ دکمه‌های قبلی/بعدی فقط برای دسترسی‌پذیری و دسکتاپ نگه داشته شده‌اند.
- زیر تصویر همیشه نام مکان و توضیح تصویر نمایش داده می‌شود.

## واترمارک و دانلود

هر تصویر ورودی گالری هنگام پردازش به نسخه WebP نشان‌دار تبدیل می‌شود. متن انگلیسی ثابت:

```text
sarzaminaryan
```

با رنگ سفید، فاصله‌گذاری بین حروف و جای ثابت پایین تصویر درج می‌شود. لینک دانلود داخل گالری به همین فایل WebP نشان‌دار وصل است.

## بهینه‌سازی خودکار تصویر

ورودی‌های مجاز:

- JPG / JPEG
- PNG
- WebP

مسیر پردازش:

1. بررسی واقعی mime فایل، نه فقط پسوند.
2. رد فایل‌های بیش از سقف مجاز.
3. بازسازی تصویر با GD برای حذف metadata، EXIF و GPS.
4. محدودکردن طول ضلع بزرگ تصویر با هدف نمایش موبایل و حفظ کیفیت.
5. درج واترمارک پایین تصویر.
6. ذخیره WebP با چند مرحله کیفیت و اندازه برای رسیدن به حجم هدف.
7. حذف فایل خام آپلودشده.
8. ثبت فایل WebP نهایی به‌عنوان attachment وردپرس.
9. اتصال attachment به استان، شهرستان و taxonomy داخلی آلبوم.

سقف پیش‌فرض:

- آپلود شهروند: ۵MB ورودی، هدف خروجی حدود ۲۲۰KB.
- آپلود مدیر: ۱۵MB ورودی، هدف خروجی حدود ۲۶۰KB.

فیلترهای قابل تنظیم:

```php
add_filter( 'sa_gallery_max_upload_bytes', function ( $bytes, $source ) {
    return 'citizen' === $source ? 5 * MB_IN_BYTES : 15 * MB_IN_BYTES;
}, 10, 2 );

add_filter( 'sa_gallery_target_bytes', function ( $bytes, $source ) {
    return 'citizen' === $source ? 220 * 1024 : 260 * 1024;
}, 10, 2 );
```

## بارگذاری مدیر سایت

در پیشخوان وردپرس:

```text
رسانه → گالری استان‌ها
```

امکانات:

- انتخاب آلبوم شهرستان.
- آپلود گروهی چند تصویر.
- ثبت نام مکان.
- ثبت توضیح تصویر.
- پردازش خودکار WebP، واترمارک و حذف فایل خام.
- انتشار مستقیم به وضعیت تأییدشده.

## تصاویر شهروندان

فرم مشارکت مردمی «شهر من» از همین پردازشگر استفاده می‌کند:

- تصویر شهروند همان لحظه سبک و WebP می‌شود.
- واترمارک درج می‌شود.
- فایل خام حذف می‌شود.
- تصویر با وضعیت `pending` ذخیره می‌شود.
- پس از تأیید مشارکت توسط مدیر، وضعیت تصویر به `approved` تغییر می‌کند و وارد آلبوم شهرستان می‌شود.
- اگر مشارکت رد شود، تصویر در گالری عمومی نمایش داده نمی‌شود.

## داده‌های داخلی

Meta key های اصلی attachment:

```text
sa_gallery_province_id
sa_gallery_city_id
sa_gallery_status
sa_gallery_source
sa_gallery_place
```

taxonomy داخلی:

```text
sa_gallery_album
```

این taxonomy عمومی نیست و فقط برای سرعت و نظم داخلی آلبوم‌ها استفاده می‌شود.

## فایل‌های اصلی

```text
wp-content/themes/sarzaminaryan-child/inc/gallery.php
wp-content/themes/sarzaminaryan-child/template-parts/entity/gallery.php
wp-content/themes/sarzaminaryan-child/assets/css/gallery.css

```

## نکته سروری

برای تبدیل خودکار به WebP، افزونه GD با پشتیبانی WebP باید روی PHP فعال باشد. اگر فعال نباشد، صفحه مدیریت گالری هشدار نشان می‌دهد و پردازش متوقف می‌شود تا فایل خام ناخواسته وارد سایت نشود.
