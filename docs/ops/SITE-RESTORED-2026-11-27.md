## ۲. آنچه هنوز باید بررسی شود (نتیجهٔ سنجش خطی)

ابزار `tools/ops/site_health.py` از داخل این سندباکس همچنان `down` می‌دهد، ولی **این دیگر نشانهٔ خرابی سایت نیست**:

- درخواست‌های مستقیم HTTP/TLS از این محیط به IPهای ایرانی بسته می‌شوند (خروجی `empty reply` و `TLS EOF` بدون هیچ پاسخ سرور).
- همان لحظه، **پروکسی بیرونی همان دامنه را با موفقیت و کامل باز می‌کند**.
- پس تفاوت از مسیر شبکه است، نه از سایت.

**کار لازم:** یک بار `site_health.py` را از یک شبکهٔ عادی (یا با VPN خاموش/روشن متفاوت) اجرا کنید تا خروجی `ok` هم ثبت شود. تا آن موقع، شاهد اصلی «باز شدن کامل صفحه از بیرون» است.

## ۳. بقیهٔ تایپو — هنوز باید اصلاح شود

دامنه در `siteurl`/`home` درست شد، ولی **۲۰۱ نوشته هنوز آدرس تصویر با تایپو دارند** (جاذبه ۳۱، راهنما ۶۷، صفحه ۵، ناوبری ۱، پیوست ۳، بازبینی ۹۴) به‌علاوهٔ ۱۰۵ `postmeta` و ۱ `users.user_url`.

یعنی بعضی تصویرهای داخل متن ممکن است لود نشوند، هرچند تصویر شاخص‌ها (که از متا می‌آیند) سالم‌اند.

**اجرای فایل آماده:**
```
docs/ops/sql/domain-typo-fix.sql
```
این فایل اول پشتیبان می‌گیرد، بعد فقط ردیف‌های دارای تایپو را اصلاح می‌کند و آخرش خودش راستی‌آزمایی می‌کند. (روی کپی واقعی داده تست شده است.)

اگر فقط می‌خواهید تصویرها را ببینید، همین یک دستور کافی است:
```sql
UPDATE IR_posts
   SET post_content = REPLACE(post_content, 'sarzaminyaran', 'sarzaminaryan')
 WHERE post_content LIKE '%sarzaminyaran%'
   AND post_type IN ('attraction','guide','page','wp_navigation','attachment');
```

## ۴. کارهای بعدی (به ترتیب)

1. **پاک‌سازی کش** — LiteSpeed Cache → Purge All (تا آدرس‌های قدیمی از کش بیرون بروند).
2. **ذخیرهٔ پیوندهای یکتا** — تنظیمات ← پیوندهای یکتا ← ذخیره (بازسازی `.htaccess`).
3. **اجرای SQL بالا** برای تصویرها.
4. **Google Search Console** — ثبت `sarzaminaryan.ir` و ارسال `wp-sitemap.xml`؛ چون سایت چند روز پایین بود، درخواست بازخزش صفحه‌های اصلی مفید است.
5. **SSL** — بررسی کنید گواهی معتبر است و `https` بدون هشدار باز می‌شود.

## ۵. درس ثبت‌شده

قطعی از یک **تایپوی ۱۳ نویسه‌ای** در `wp_options` بود، نه از هاست، نه از DNS و نه از SSL. عیب‌یابی دو روزه صرف لایه‌هایی شد که سالم بودند. از این پس اولین دستور در هر قطعی:

```sql
SELECT option_name, option_value FROM IR_options WHERE option_name IN ('siteurl','home');
```
