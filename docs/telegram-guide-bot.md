# ربات راهنمای تلگرام (قالب فرزند — از v2.11.33)

رباتی که **درونِ خودِ قالب** اجرا می‌شود (بدون افزونه) و بازدیدکننده را قدم‌به‌قدم در سایت راهنمایی می‌کند:

```
/start → فهرست استان‌ها → انتخاب استان (خلاصه + لینک + شهرها)
                        → انتخاب شهر (خلاصه + لینک + دیدنی‌ها)
                        → انتخاب دیدنی (خلاصه + لینک مستقیم به صفحهٔ سایت)
```

همچنین اگر کاربر **نامِ هر استان، شهر یا دیدنی را تایپ کند**، ربات جستجو می‌کند و نتیجه را به‌صورت دکمه نشان می‌دهد.

---

## ۱. پیش‌نیازها (یک‌بار بررسی کنید)

| مورد | چرا لازم است | چطور بررسی کنیم |
| --- | --- | --- |
| سایت روی `https` | تلگرام فقط وب‌هوکِ امن (SSL) را می‌پذیرد | نشانی سایت در مرورگر باید قفلِ سبز داشته باشد |
| REST API فعال باشد | ربات پیام‌ها را از مسیر `/wp-json/...` می‌گیرد | در مرورگر `https://سایت‌شما/wp-json/` را باز کنید؛ باید JSON ببینید (اگر افزونه‌ای REST را بسته، آن را برای این مسیر استثنا کنید) |
| توکنِ ربات | همان توکنی که @BotFather داده است | اگر بخش «شبکه‌های اجتماعی» از قبل وصل است، نیازی به توکنِ جدا نیست (پایین در گام ۳) |
| دسترسیِ مدیر | فقط کاربر با توانایی `manage_options` تنظیمات را می‌بیند | با حساب مدیر وارد شوید |

> **نکتهٔ مهم:** این ربات به **WP-Cron وابسته نیست**؛ چون تلگرام پیام را همان لحظه به سایت می‌فرستد (وب‌هوک)، پاسخ فوری است.

---

## ۲. گام‌به‌گامِ راه‌اندازی (حدود ۵ دقیقه)

### گام ۱ — ساخت ربات در BotFather (اگر ندارید)

1. در تلگرام به [@BotFather](https://t.me/BotFather) بروید و `/newbot` را بفرستید.
2. نامِ نمایشی را بفرستید (مثلاً «راهنمای سرزمین آریان»).
3. نام کاربری را با پسوند `bot` بفرستید (مثلاً `SarzaminAryanGuideBot`).
4. پیامِ موفقیت شامل **توکن** است؛ آن را کپی کنید.
5. یک‌بار روی لینکِ ربات بزنید و `/start` را بفرستید (تلگرام تا اولین پیام، بعضی تنظیمات را فعال نمی‌کند).

> اگر برای انتشارِ خودکار در کانال از قبل ربات ساخته‌اید، **همان ربات کافی است** و نیازی به رباتِ دوم نیست.

### گام ۲ — تنظیمِ ظاهر و دستورها (اختیاری ولی حرفه‌ای)

در @BotFather این دستورها را برای ربات اجرا کنید:

- `/setdescription` → «راهنمای سفرِ سرزمین آریان: استان، شهر و دیدنی را انتخاب کنید.»
- `/setabouttext` → توضیحِ کوتاهِ یک‌خطی.
- `/setuserpic` → نشان/لوگوی سایت.
- `/setcommands` → این فهرست را بفرستید:

```
start - شروع و نمایش استان‌ها
help - راهنما
province - فهرست استان‌ها
```

- `/setprivacy` → **Disable** را انتخاب کنید (فقط در صورتی که بخواهید ربات در گروه‌ها هم پاسخ بدهد؛ برای گفتگوی خصوصی لازم نیست).

### گام ۳ — وارد کردنِ تنظیمات در سایت

مسیر: **پیشخوان → سرزمین آریان → ربات تلگرام** (`admin.php?page=sa-telegram-bot`)

1. **توکن ربات** — توکنِ BotFather را اینجا بگذارید.
   - اگر این فیلد را **خالی بگذارید**، ربات از همان توکنِ تلگرامِ صفحهٔ **سرزمین آریان → شبکه‌های اجتماعی** استفاده می‌کند (یعنی اگر آنجا از قبل وصل است، کافی است اینجا ذخیره را بزنید).
   - توکن هیچ‌وقت در صفحه چاپ نمی‌شود؛ فقط پیشوند و پسوندِ آن به‌صورت نقاب‌دار (`1234••••ABCD`) نمایش داده می‌شود.
   - برای تغییر ندادن، فیلد را خالی بگذارید؛ ذخیره کردن، توکنِ قبلی را پاک نمی‌کند.
2. **نام کاربری ربات** — بدون @ (مثلاً `SarzaminAryanGuideBot`)؛ فقط برای این‌که صفحه، لینکِ `t.me/...` را به شما نشان بدهد.
3. **پیام خوش‌آمد / پیام راهنما** — متن‌های پیش‌فرض را می‌توانید به دلخواه تغییر دهید.
4. **طول خلاصه** (پیش‌فرض ۲۴۰ نویسه) و **تعداد در هر صفحه** (پیش‌فرض ۸).
5. **شناسهٔ گفتگو برای تست** — شناسهٔ عددیِ تلگرامِ خودتان (یا `@کانال`) تا با دکمهٔ «ارسال پیام تست» خوش‌آمد را برایتان بفرستد. شناسهٔ عددی را با فرستادن پیام به ربات‌هایی مانند @userinfobot به‌دست می‌آورید.
6. تیکِ **«ربات فعال باشد…»** را بزنید و **ذخیرهٔ تنظیمات** را فشار دهید.

### گام ۴ — تنظیمِ وب‌هوک (یعنی اتصالِ تلگرام به سایت)

در همان صفحه، پایینِ جدولِ «تنظیمات»، بخشِ **وب‌هوک (دریافت پیام‌ها)** را می‌بینید:

1. نشانیِ وب‌هوک را کپی کنید (شبیه `https://سایت‌شما/wp-json/sa/v1/telegram-bot/xxxxxxxxxxxxxxxx`).
   - بخش آخرِ نشانی یک **رشتهٔ محرمانه** است که فقط مدیر آن را می‌بیند؛ تلگرام نمی‌تواند بدون آن به ربات شما پیام بفرستد.
2. دکمهٔ **«تنظیم وب‌هوک»** را بزنید. اگر همه‌چیز درست باشد، پیامِ سبز «وب‌هوک با موفقیت تنظیم شد» می‌بینید.
3. جدولِ «وضعیت» را نگاه کنید:
   - **نشانیِ ثبت‌شده در تلگرام** باید همان نشانیِ بالا باشد.
   - **پیام‌های در انتظار** عددِ پیام‌هایی است که تلگرام نتوانسته تحویل بدهد؛ اگر بعد از چند دقیقه کم نشد، بخشِ عیب‌یابی را ببینید.

> هر وقت نشانی سایت عوض شد (تغییر دامنه، جابه‌جاییِ هاست، رفتن از http به https)، دوباره **«تنظیم وب‌هوک»** را بزنید.

### گام ۵ — تستِ واقعی

1. در تلگرام، ربات خود را باز کنید و `/start` را بفرستید.
2. ربات باید پیام خوش‌آمد + دکمه‌های استان‌ها را بفرستد.
3. یک استان را لمس کنید → خلاصهٔ استان + دکمهٔ «مشاهدهٔ صفحهٔ استان در سایت» + دکمهٔ شهرها.
4. یک شهر را لمس کنید → خلاصهٔ شهر + لینک + دکمهٔ دیدنی‌ها.
5. یک دیدنی را لمس کنید → خلاصهٔ کوتاه + لینک مستقیم به صفحهٔ سایت.

اگر پاسخی نیامد، فوراً بخشِ **۷. عیب‌یابی** را بخوانید.

### گام ۶ — معرفی ربات در کانال (پیشنهاد)

برای این‌که مخاطبانِ کانال با یک لمس وارد ربات شوند، در کانال پیامی با این لینک بفرستید:

```
https://t.me/USERNAME_BOT?start=channel
```

همچنین می‌توانید ربات را **ادمینِ کانال** کنید تا بتواند پیام بفرستد (برای انتشارِ خودکار لازم است؛ برای راهنماییِ بازدیدکننده لازم نیست).

---

## ۳. رفتارِ گفتگو (دقیقاً چه می‌فرستد)

| ورودیِ کاربر | پاسخِ ربات |
| --- | --- |
| `/start` | پیام خوش‌آمد + دکمه‌های استان‌ها (صفحه‌بندی‌شده) |
| `/help` یا `راهنما` | پیام راهنما |
| `/province` یا `استان‌ها` | فقط فهرست استان‌ها |
| هر متنِ دیگر | **جستجو** در استان‌ها، شهرها و دیدنی‌ها (تا ۶ نتیجه به‌صورت دکمه) |
| لمسِ یک استان | خلاصهٔ استان + دکمهٔ لینک به صفحهٔ استان + دکمهٔ شهرها |
| لمسِ یک شهر | خلاصهٔ شهر + دکمهٔ لینک به صفحهٔ شهر + دکمهٔ دیدنی‌ها + دکمهٔ «شهرهایِ این استان» |
| لمسِ یک دیدنی | خلاصهٔ دیدنی + نامِ شهر + لینک مستقیمِ صفحه در متن + دکمهٔ «مشاهدهٔ کامل در سایت» |
| دکمه‌های `◀︎ قبلی` / `بعدی ▶︎` | صفحهٔ قبل/بعدِ همان فهرست |
| دکمهٔ `🏠 استان‌ها` | بازگشت به فهرست استان‌ها |

- خلاصه‌ها از **چکیدهٔ نوشته** ساخته می‌شوند و اگر چکیده خالی باشد، از متنِ بدنه (بدون تگ و شورت‌کد)؛ طولِ آن با تنظیمِ «طول خلاصه» محدود می‌شود.
- فقط نوشته‌های **منتشرشده** نمایش داده می‌شوند.
- اگر برای یک استان/شهر هنوز محتوایی ثبت نشده باشد، ربات صادقانه می‌گوید «برای این شهر هنوز دیدنی‌ای ثبت نشده است» و لینکِ صفحه را می‌دهد.

## ۴. تنظیمات در یک نگاه

| تنظیم | پیش‌فرض | توضیح |
| --- | --- | --- |
| فعال‌سازی | خاموش | تا وقتی روشن نباشد، وب‌هوک پاسخِ ۵۰۳ می‌دهد |
| توکن ربات | خالی | خالی = استفاده از توکنِ بخشِ «شبکه‌های اجتماعی» |
| نام کاربری ربات | خالی | فقط برای نمایش لینک `t.me/...` |
| پیام خوش‌آمد | متنِ آماده | بعد از `/start` |
| پیام راهنما | متنِ آماده | بعد از `/help` و فرمان‌های ناشناس |
| طول خلاصه (نویسه) | ۲۴۰ | ۶۰ تا ۹۰۰ |
| تعداد در هر صفحه | ۸ | ۳ تا ۲۰؛ تعداد دکمه‌های هر صفحه |
| شناسهٔ گفتگو برای تست | خالی | مقصدِ دکمهٔ «ارسال پیام تست» |

گزینه‌ها در جدولِ `wp_options` با کلیدهای `sa_telegram_bot` (تنظیمات) و `sa_telegram_bot_log` (۱۵ ردیفِ آخرِ درخواست‌ها) ذخیره می‌شوند.

## ۵. وب‌هوک: سه عملیاتِ صفحه

| دکمه | چه می‌کند |
| --- | --- |
| **تنظیم وب‌هوک** | نشانیِ رازدارِ قالب را به تلگرام معرفی می‌کند (`setWebhook`) |
| **حذف وب‌هوک** | ربات را از دریافت پیام بازمی‌دارد (`deleteWebhook`) — برای نگه‌داری یا انتقالِ سایت مفید است |
| **ارسال پیام تست** | پیامِ خوش‌آمد و دکمهٔ استان‌ها را به «شناسهٔ گفتگو برای تست» می‌فرستد |

بعد از هر عملیات، نتیجه در **گزارشِ آخرین درخواست‌ها** (پایینِ صفحه) ثبت می‌شود: زمان، رویداد، موفق/ناموفق و توضیح.

---

## ۶. امنیت

- نشانیِ وب‌هوک یک **رشتهٔ محرمانهٔ ۳۲ کاراکتری** دارد که هنگامِ اولین ذخیره ساخته و در `sa_telegram_bot` ذخیره می‌شود؛ درخواست‌های بدونِ رازِ درست، **۴۰۳** می‌گیرند.
- توکن در خروجیِ HTML **نقاب‌دار** است و هیچ‌وقت در صفحه چاپ نمی‌شود.
- همهٔ عملیات‌های مدیریتی با `manage_options` و `nonce` محافظت می‌شوند.
- ربات فقط **خواندن** انجام می‌دهد: هیچ نوشته‌ای را ایجاد یا تغییر نمی‌دهد.
- اگر ربات را خاموش کنید، مسیرِ وب‌هوک **۵۰۳** برمی‌گرداند و تلگرام پیام را بعداً دوباره می‌فرستد؛ برای توقفِ کامل، «حذف وب‌هوک» را بزنید.

## ۷. عیب‌یابی

| نشانه | علتِ احتمالی | راه‌حل |
| --- | --- | --- |
| ربات اصلاً پاسخ نمی‌دهد | ربات غیرفعال یا توکن خالی است | تیکِ فعال‌سازی + توکن را بررسی کنید |
| «وب‌هوک با موفقیت تنظیم شد» ولی پاسخ نمی‌آید | REST مسدود است (افزونهٔ امنیتی/کش) | `/wp-json/sa/v1/...` را در استثناها بگذارید؛ کشِ صفحه را پاک کنید |
| خطای SSL هنگامِ تنظیم وب‌هوک | گواهیِ ناقص یا زنجیرهٔ ناقص | گواهی را کامل نصب کنید (شاملِ زنجیره)؛ تلگرام گواهیِ خودامضا را نمی‌پذیرد |
| «نشانیِ ثبت‌شده در تلگرام» خالی است | وب‌هوک تنظیم نشده | دکمهٔ «تنظیم وب‌هوک» را دوباره بزنید |
| «پیام‌های در انتظار» بالا می‌رود | سایت خطای ۵۰۰ می‌دهد یا نشانی عوض شده | گزارشِ ربات را ببینید، سپس دوباره وب‌هوک را تنظیم کنید |
| پیام‌های تکراری می‌آید | دو جا وب‌هوک تنظیم شده است | فقط همین نشانی را نگه دارید و دوباره «تنظیم وب‌هوک» را بزنید |
| دکمه‌ها ظاهر می‌شوند ولی لمسِ آن‌ها بی‌اثر است | نسخهٔ قدیمیِ تلگرام | تلگرام را به‌روز کنید؛ ساختارِ پاسخ استانداردِ Bot API است |
| «استانی در سایت منتشر نشده است» | هیچ نوشتهٔ منتشرشده‌ای از نوع «استان» ندارید | ابتدا استان‌ها را منتشر کنید (ابزارِ «ارسالِ انبوه» هم همین‌ها را می‌فرستد) |

## ۸. برای توسعه‌دهنده

**مسیرِ رستِ وب‌هوک**

```
POST https://سایت/wp-json/sa/v1/telegram-bot/{secret}
```

بدنه همان شیءِ `Update` تلگرام است (JSON). پاسخ همیشه `{"ok":true}` با کد ۲۰۰ است (مگر ۴۰۳ برای رازِ اشتباه و ۵۰۳ برای رباتِ غیرفعال).

**تابع‌های اصلی** (`inc/telegram-bot.php`)

| تابع | کار |
| --- | --- |
| `sa_tgbot_defaults()` / `sa_tgbot_settings()` | پیش‌فرض‌ها و تنظیماتِ ادغام‌شده |
| `sa_tgbot_token()` | توکنِ اختصاصی یا توکنِ بخشِ شبکه‌های اجتماعی |
| `sa_tgbot_secret()` / `sa_tgbot_webhook_url()` | راز و نشانیِ وب‌هوک |
| `sa_tgbot_api( $method, $args )` | فراخوانیِ Bot API |
| `sa_tgbot_send( $chat_id, $text, $markup )` | ارسال پیام با `parse_mode=HTML` |
| `sa_tgbot_send_home/provinces/province/city/post_card()` | گام‌های گفتگو |
| `sa_tgbot_search( $q )` | جستجو در استان/شهر/دیدنی |
| `sa_tgbot_handle_update( $update )` / `sa_tgbot_handle_callback()` | پردازشِ پیام و کلیک |
| `sa_tgbot_webhook( $request )` | ورودیِ مسیرِ رست |
| `sa_tgbot_log_add()` / `sa_tgbot_logs()` | گزارشِ ۱۵ ردیفه |

**فیلترها**

- `sa_tgbot_send_args` — تغییرِ payloadِ هر پیام پیش از ارسال.

**داده‌ها**: استان‌ها با `get_posts(['post_type' => 'province'])`, و شهرها/دیدنی‌ها از طریق `sa_get_children()` و `sa_get_parent()` در `inc/relations.php` (همان روابطِ قالب) خوانده می‌شوند؛ در صورت نبودِ آن توابع، ربات به کوئریِ مستقیمِ متا (`sa_province_id` / `sa_city_id`) برمی‌گردد.

## ۹. سنجشِ کیفیت (تست‌ها)

```
node tools/phpwasm/exec.js tools/sa-tests/run-bot.php   # ۱۰۸ ادعا
PHP_VER=7.4 node tools/phpwasm/exec.js tools/sa-tests/run-bot.php
```

تست‌ها با شبیه‌سازِ وردپرس در `tools/sa-tests/wp-stubs.php` اجرا می‌شوند و شاملِ مسیرِ کاملِ گفتگو، صفحه‌بندی، جستجو، وب‌هوک (۴۰۳/۵۰۳/۲۰۰)، تنظیمِ وب‌هوک، پاک‌سازیِ ورودی‌ها و رندرِ صفحهٔ مدیریت هستند.
