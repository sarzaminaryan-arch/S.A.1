# تحویل کار برای رفع ریسپانسیو موبایل صفحهٔ اول

تاریخ ثبت: 2026-10-18

## وضعیت فعلی

- نسخهٔ منتشرشدهٔ قالب: `2.22.12`
- آخرین commit شاخه: `a6d82f6`
- انتشار GitHub: `sarzaminaryan-child-v2.22.12`
- مشکل ریسپانسیو در حالت موبایل هنوز حل نشده است.
- این نشست فقط برای ثبت گزارش و مستندسازی بود؛ هیچ اصلاح جدیدی در CSS، HTML یا JavaScript برای رفع ریسپانسیو انجام نشد.

## کارهای انجام‌شده تا این مرحله

1. در commit `79c7a27`، اصلاحات پروفایل‌های استان/شهرستان/دیدنی شامل پالتی navy، سایه‌های عمیق‌تر، هالهٔ لینک‌های فعال، تفاوت جعبه‌های بدون لینک، فهرست‌های فشرده و قواعد موبایل ثبت شد.
2. در commit `1e8c16e`، فهرست آخرین/مرتبط، فهرست آموزش‌ها و فهرست دیدنی‌ها از `template-home.php` حذف شد.
3. لوگوی مستقل هیرو و لوگوی داخلی رتبه‌بندی شهرها حذف شدند؛ لوگوهای `header.php` و `footer.php` باقی ماندند.
4. بلوک مستقل `CC_UI::top_cities_block(7)` حفظ شد، چون رتبه‌بندی شهرهاست و جزو فهرست مقاله/آموزش/دیدنی نیست.
5. تنظیمات، متغیرها و queryهای مخصوص فهرست‌های حذف‌شده پاک‌سازی شدند.
6. تست `test-article-cards.php` در `a6d82f6` با وضعیت جدید صفحهٔ اول هماهنگ شد تا حذف فهرست‌های صفحهٔ اول را بررسی کند و قرارداد کارت‌های آرشیو را نگه دارد.
7. نسخهٔ `2.22.12` با موفقیت در GitHub Actions lint، تست و package شد و فایل ZIP انتشار ساخته شد.

## فایل‌های مرتبط برای بررسی نشست بعدی

- `wp-content/themes/sarzaminaryan-child/template-home.php`
  - CSS inline هیرو، نقشه، جست‌وجو، چیپ‌ها، شمارنده‌ها و breakpointهای صفحهٔ اول.
- `wp-content/themes/sarzaminaryan-child/assets/css/child.css`
  - قواعد scoped پروفایل‌ها، لیست‌های navy و responsive profile layout.
- `wp-content/themes/sarzaminaryan-child/assets/css/city-contrib.css`
  - responsive بلوک رتبه‌بندی شهرها و اجزای مشارکت شهری.
- `wp-content/themes/sarzaminaryan-child/template-parts/entity/`
  - markup شناسنامه‌های province/county/attraction.
- `wp-content/themes/sarzaminaryan-child/header.php` و `footer.php`
  - لوگوهای مجاز هدر و فوتر؛ نباید حذف شوند.
- `wp-content/themes/sarzaminaryan-child/assets/js/counter-buttons.js`
  - رفتار شمارنده؛ باید footer-loaded و محدود به `is_front_page()` باقی بماند.

## محدودیت‌های لازم برای اصلاح بعدی

- فهرست‌های مقاله، آموزش و دیدنی را به صفحهٔ اول برنگردانید.
- لوگوی مستقل داخل صفحهٔ اول را برنگردانید؛ فقط لوگوهای هدر و فوتر مجازند.
- بلوک رتبه‌بندی شهرها را فقط در صورت اثبات تعارض واقعی با نیازمندی‌ها تغییر دهید.
- تغییرات navy، shadow، linked-only glow، non-linked distinction و ساختار `.profile-page` را حفظ کنید.
- رفتار شمارنده و معماری assetها را تغییر ندهید مگر با دلیل و تست.
- ابتدا مشکل واقعی را در viewportهای موبایل بازتولید و محل overflow/شکست layout را مشخص کنید؛ از حدس‌زدن و اصلاح گستردهٔ CSS خودداری شود.
