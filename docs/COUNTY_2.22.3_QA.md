# فاز ۳ — قالب شهرستان، نسخهٔ ۲٫۲۲٫۳

تاریخ: ۲۰۲۶-۱۰-۱۷ · شاخه: `arena/a32fb27a-s-a-1` · مجوز صریح مالک برای اجرا و push.

## تغییرات
- مسیر اصلی `single-city.php` از fallback مشترک `template-parts/entity/single.php`
  استفاده می‌کند؛ اصلاح در همان مسیر واقعی و با شرط city انجام شد.
- ماژول مستقل `inc/county-page.php` و CSS مستقل `assets/css/county-page.css` اضافه شد.
- مشخصات کلی با مرزهای h2/h3 از خروجی مقاله برداشته و اطلاعات غیرتکراری‌اش داخل
  شناسنامه درج می‌شود. هیچ نوشته/متای مقاله بازنویسی نمی‌شود.
- فقط جدول دو ستونه‌ای حذف می‌شود که تمام سطرهایش دقیقاً با داده‌های شناخته‌شدهٔ
  شناسنامه برابر باشند. جدول متفاوت، واحد متفاوت و سطر ناشناخته حفظ می‌شود.
- شناسنامه با پالت زرد/نارنجی، جداکنندهٔ فارسی/انگلیسی، سلول‌های رشدپذیر بدون
  track خالی و برچسب‌های کنارهم برای جاذبه‌ها نمایش داده می‌شود.
- Google Maps از URL کنترل‌شده با مختصات معتبر یا نام شهرستان/استان ساخته می‌شود؛
  iframeهای قدیمی Google/OSM در متن کنار گذاشته می‌شوند. embed خارجی استثنای صریح
  خواستهٔ مالک است؛ دسترسی گوگل، CSP و رضایت/حریم خصوصی باید روی هاست بررسی شوند.
- گالری موجود پیش از متن اصلی حفظ می‌شود تا FAQ بلافاصله به فرم ارسال دیدنی برسد.
- ترتیب پایین صفحه: حقایق جالب (اگر موجود) ← FAQ (از متن یا متا) ← فرم ارسال دیدنی
  ← مقالات مرتبط ← قبلی/بعدی ← منابع. درخواست تکراری از مردم حذف می‌شود.
- related با WP_Query و rand است؛ استان کانونی province_id اولویت دارد و
  sa_province_id فقط fallback است؛ استان نامعلوم، صفر و استان جاری وارد نتیجه نمی‌شوند.

## مقیاس امتیاز: قرارداد سازگاری
- UI و REST اکنون ۱ تا ۵ هستند؛ ۶ و ۷ در API جدید پذیرفته نمی‌شوند.
- جدول موجود و رأی‌های تاریخی بازنویسی نشدند. برای سازگاری و بازگشت‌پذیری، ورودی
  ۱/۲/۳/۴/۵ با نگاشت ۱/۳/۴/۶/۷ ذخیره و با round(stored*5/7) خوانده می‌شود.
- توزیع، مجموع، میانگین و رتبه از رأی‌های تبدیل‌شده محاسبه می‌شوند؛ متای قدیمی
  هفت‌ستاره برای خروجی عمومی خوانده نمی‌شود. کش رتبهٔ پنج‌ستاره مستقل است و پس از رأی
  پاک می‌شود. ابزارهای مدیریتی قدیمی که متا را مستقیم می‌خوانند ممکن است همچنان
  آمار مقیاس ذخیره‌سازی قدیمی را نشان دهند؛ مهاجرت آن‌ها خارج از این فاز است.
- nonce برای POST و منتشرشده‌بودن شهرستان در GET/POST کنترل می‌شود. رأی مهمان
  عمداً مجاز مانده؛ nonce مشترک مهمان جای احراز هویت یا ضدتقلب نیست و ممیزی ضدتقلب
  کامل نشده است. محدودیت روزانه و قفل ۲۴ ساعتهٔ قبلی باقی است.

## منابع
- URLهای واقعی متا، متن، پانویس و پاسخ‌های FAQ جمع می‌شوند؛ google.com و زیردامنه‌ها
  حذف و فقط یک ویکی‌پدیا حفظ می‌شود. URL تکراری بدون fragment یک منبع حساب می‌شود.
- فقط HTTP(S) معتبر پذیرفته می‌شود؛ اولویت با HTTPS و دامنه‌های رسمی با مرزبندی
  دقیق host است؛ هیچ درخواست HEAD/GET برای URLهای واردشده در بازدید عمومی اجرا نمی‌شود.
- سقف ۱۰؛ اگر حداقل ۵ منبع واقعی موجود نباشد، جعل/تکثیر منبع نمی‌شود و مدیرِ مجاز
  هشدار تکمیل می‌بیند. اعتبار HTTP، محتوای منبع و ارتباط موضوعی تضمین نشده‌اند.
- Regex ارجاع عددی روی text node اجرا می‌شود، نه URL/attribute/code/pre؛ توان علمی
  مثل sup بدون کلاس ارجاع/پیوند حفظ می‌شود. منابع در یک بخش انتهایی نمایش داده می‌شوند.
