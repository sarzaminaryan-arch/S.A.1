## ✍️ تمپلیت نگارش مقالات این بخش

### ساختار ثابت هر مقاله:

```

۱. بلوک SEO (بالای مقاله - برای مدیر سایت)

   - عنوان سئو (Title Tag)

   - متا توضیحات (Meta Description)

   - کلمه کلیدی اصلی (Focus Keyword)

   - کلمات کلیدی فرعی

   - نامک (Slug)

   - اسکیما (Schema Markup)

   - چکیده مقاله

۲. تیتر اصلی (H1)

   - صمیمی، مستقیم، حاوی کلمه کلیدی

۳. مقدمه آرامش‌بخش

   - مخاطب رو آروم می‌کنیم

   - حس واقعی موقعیت رو منتقل می‌کنیم

   - می‌گیم «نترس، با هم حلش می‌کنیم»

۴. آموزش قدم‌به‌قدم

   - شماره‌گذاری واضح

   - هر قدم کوتاه و قابل فهم

   - بعد از هر مرحله اگه جایگزین خلاقانه داره ← بگو

   - اگه ابزار لازمه ← معرفی + جایگزین

۵. نکات مهم و هشدارها

   - با آیکون ⚠️ یا ❌ مشخص بشن

   - باورهای غلط رو رد کن

۶. سوالات رایج (FAQ)

   - هر سوالی که ممکنه ذهن مخاطب رو درگیر کنه

   - پاسخ ساده و کوتاه

   - اگه جواب مفصله ← لینک به مقاله مرتبط

۷. جمع‌بندی سریع (چک‌لیست ذهنی)

   - به شکل فلوچارت ساده متنی

   - قابل حفظ کردن

۸. لینک‌های مرتبط

   - مقالات مرتبط داخل همین بخش

   - لینک صفحه اصلی آموزش‌ها

۹. پیام پایانی

   - صمیمی و دلسوزانه

   - تذکرهای مراقبتی خاص موضوع مقاله

   - مثلاً: مراقب بچه‌ها باشید، آتیش رو خاموش کنید و...

```

### لحن نگارش:

```

- صمیمی مثل رفیق نه رسمی مثل کتاب درسی

- «تو» خطاب می‌کنیم نه «شما»

- از ایموجی استفاده می‌کنیم ولی زیاده‌روی نه

- جمله‌ها کوتاه

- هر پاراگراف حداکثر ۳-۴ خط

- از تجربه واقعی مردم نقل‌قول ضمنی می‌آریم

- باورهای غلط رو مستقیم رد می‌کنیم

- همیشه جایگزین خلاقانه داریم

- آخر هر مقاله حس امنیت و امید می‌دیم

- مثل یه داداش بزرگ‌تر حرف می‌زنیم

  نه ترسناک، نه بی‌خیال

```

### قوانین تولید محتوا:

```

۱. اطلاعات الکی = ممنوع. اگه مطمئن نیستی ننویس.

۲. لینک خرید = ممنوع. فقط معرفی.

۳. تبلیغ برند خاص = ممنوع.

۴. طول مقاله = هرچقدر نیاز بود. کوتاه نکن بخاطر طول.

۵. سوالات FAQ = حداقل ۵ عدد.

۶. جایگزین خلاقانه = حتماً در هر مقاله حداقل ۱ مورد.

۷. پیام پایانی مراقبتی = حتماً.

۸. لینک داخلی = حداقل ۲ مقاله مرتبط.

۹. اسکیما FAQ و HowTo = حتماً برای هر مقاله.

```
