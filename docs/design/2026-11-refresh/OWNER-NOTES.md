# دستورهای تکمیلی مالک — ۲۹ آبان ۱۴۰۵ (۲۹ نوامبر ۲۰۲۶)

سه سند همراه طرح‌ها (برگه‌های «قالب صفحه شهرستان»، «قالب صفحه گنجینه دیدنی‌های
ایران» و «صفحه اصلی دانشنامه») حاوی تصمیم‌های اجرایی‌اند. این فایل همان‌ها را ثبت
می‌کند تا هیچ‌کدام در پیاده‌سازی گم نشود.

## ۱) قالب شهرستان (هم‌سبک با صفحهٔ استان)

## ۲) گنجینه دیدنی‌های ایران

| خواستهٔ مالک | وضعیت | جای پیاده‌سازی |
| --- | --- | --- |
| نام بخش در منو و لینک‌ها: «گنجینه دیدنی‌های ایران» | ✅ | `sa_2026_nav_items()`، `sa_2026_footer_explore()`، بردکرامب و H1 |
| صفحهٔ مادر با فیلتر استان، شهرستان و نوع (تاریخی/طبیعی/مذهبی/بوم‌گردی) | ✅ | `archive-attraction.php` + `sa_2026_treasure_*` در `inc/design-2026.php` (فیلتر GET: `province_tax`، `sa_county`، `attraction_type`، `s`) |
| شناسهٔ اختصاصی هر دیدنی به شکل `POI-TBZ-001 // SYS.ID` | ✅ | `sa_2026_poi_code()`؛ کد شهر از `sa_poi_city_code` (قابل بازنویسی با متای `sa_poi_code`) |
| لینک بازگشت به شهرستان و استان | ✅ | بردکرامب چهارسطحی + شناسنامه + بنر پایانی `single-attraction.php` |
| اسکیمای BreadcrumbList + TouristAttraction | ✅ (از قبل موجود) | `inc/schema.php` → `sa_schema_entity()` و `sa_schema_breadcrumbs()` |
| آدرس `sarzaminaryan.ir/treasure/…` | ⚠️ موقت: ۳۰۱ به `/attraction/…` | `sa_2026_treasure_alias_redirect()` |

**تصمیم باز (نیازمند تأیید مالک):** تغییر مبنای آدرس از `/attraction/` به
`/treasure/` یعنی بازنشسته‌کردن **۳۸ آدرس ایندکس‌شده** (فهرست زندهٔ
`wp-sitemap-posts-attraction-1.xml`). تا تأیید نشود، شکل درخواستی مالک با ۳۰۱ دائمی
(`/treasure/<slug>` → `/attraction/<slug>` و `/treasure/` → صفحهٔ مادر) پاسخ می‌گیرد؛
هیچ آدرسی نمی‌شکند و ایندکس فعلی حفظ می‌شود. برای مهاجرت کامل، این زنجیره لازم است:
`url_base` در `data-model/schema/data-model.yaml` → `python3 data-model/schema/build_child_config.py`
→ `data/redirects.php` (تبدیل مقصدهای `/attraction/…` به `/treasure/…`) → flush
rewrite → بازبینی `sa_redirect_target_exists` و به‌روزرسانی گاردهای پیوند داخلی.

## ۳) صفحهٔ اصلی

| خواستهٔ مالک | وضعیت |
| --- | --- |
| جست‌وجوی آنی + چیپ‌های فیلتر دسته | ✅ `front-page.php` + `sa-2026.js` (ایندکس JSON از استان/شهرستان/دیدنی) |
| چهار ستون کاوش (۰۱ تا ۰۴) | ✅ ستون‌های استان‌ها، شهرستان‌ها، گنجینه دیدنی‌ها، آموزش سفر |
| تب‌های تعاملی منتخب فصل / رتبه‌بندی / گنجینه | ✅ به‌صورت بخش «استان‌های شاخص» + «تازه‌ترین‌ها» (تب مجزا لازم نشد؛ دادهٔ رتبه‌بندی در مخزن وجود ندارد و ساخته نشد) |
| تجربهٔ مسافرها با مودال ثبت | ✅ مودال مشترک + CTA در فوتر و صفحه‌ها |
| محتوای تحریریهٔ سئو | ✅ بخش «دربارهٔ دانشنامه» |
| JSON-LD سازمان + WebSite (SearchAction) | ✅ از قبل در `inc/schema.php` (`sa_schema_website()` فقط در صفحهٔ اول) |

## قاعده‌های داده‌ای که در این اجرا رعایت شد

- هیچ عدد، امتیاز محبوبیت یا فاصله‌ای ساخته نشد؛ هر جا داده نبود، متن جایگزین شد.
- آمار استان/شهرستان فقط از `data/province-profiles.json` و `data/region-facts.php`.
- جمعیت با ذکر مبنای سرشماری و گرد‌شده نمایش داده می‌شود.
- رتبه‌بندی مقصدها تا وقتی دادهٔ منبعی در مخزن نباشد، در قالب نمایش داده نمی‌شود.
