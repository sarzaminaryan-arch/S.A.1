# گزارش پیشرفت ممیزی — نسخهٔ ۱٫۶

- **درخواست تازه:** فایل GitHub ZIP قابل نصب می‌خواهید و می‌خواهید ابزار «از صفر تا صد» اطلاعات لازم برای تحلیل سایت را گردآوری کند.
- **نسخهٔ ابزار:** افزونه به **SA Site Audit Exporter 1.1.0** گسترش یافت. فایل نصب از شاخهٔ کاری GitHub قابل دریافت خواهد بود؛ پیوند مستقیم بعد از push همین نسخه ارائه می‌شود.
- **اتصال مستقیم از Agent:** همچنان به دامنهٔ زنده دسترسی شبکه ندارم؛ هیچ درخواست زنده‌ای از این sandbox ارسال نشده است.
- **سایت زنده:** افزونه هنوز توسط مالک نصب/اجرا نشده و هیچ داده یا محتوایی در سایت تغییر نکرده است.

## پوشش نسخهٔ 1.1.0

### خروجی اول — موجودی و متن ذخیره‌شده
- همهٔ post typeهای عمومی به‌جز رسانه‌ها؛ فقط رکوردهای `publish`، با سقف ۵۰۰۰.
- عنوان، نامک، URL، تاریخ انتشار/ویرایش، excerpt و متن ذخیره‌شده، خلاصهٔ هدینگ/واژه/لینک، taxonomyهای عمومی و metaهای SEO/روابط از allowlist محدود.
- شمار فقط رکوردهای منتشرشده؛ draft/private و اطلاعات کاربران یا تنظیمات/گزینه‌ها صادر نمی‌شوند.

### خروجی دوم — crawl ساختاری HTML رندرشده
- صفحهٔ اصلی، `robots.txt` و مسیرهای رایج sitemap، آرشیوهای عمومی، taxonomyهای عمومیِ دارای محتوا و permalink تمام رکوردهای منتشرشدهٔ عمومی در تمام post typeها به‌جز attachment؛ سقف ۱۰٬۰۰۰ URL.
- برای هر URL: status و content-type، title، meta description، canonical، robots، Open Graph/Twitter، زبان/جهت، کلاس بدنه، متن و شمار هدینگ‌ها، شمار واژهٔ تقریبی، breadcrumb، JSON-LD types، پیوندهای داخلی/خارجی، تصویرها و alt.
- crawl فقط در مرورگر مدیر و همان origin اجرا می‌شود؛ redirect دنبال نمی‌شود، محتوای HTML خام/اطلاعات فرم دانلود نمی‌شود و درخواست upload/API بیرونی وجود ندارد.
- تعداد صفحات و پیشرفت نمایش داده می‌شود؛ اجرای کامل روی سایت بزرگ ممکن است چند دقیقه طول بکشد. اگر سقف ۵۰۰۰/۱۰٬۰۰۰ فعال شود یا مدیر متوقف کند، این وضعیت در JSON ثبت می‌شود.

### خارج از دامنهٔ حفاظتی

«همه‌چیز» در این ابزار یعنی دادهٔ عمومی و مرتبط با ممیزی؛ نه حساب/رمز، کاربران، پیش‌نویس/خصوصی، سفارش، دیدگاه، فرم‌های ارسالی، همهٔ options یا Analytics/Search Console. اطلاعات GA4 و GSC جدا از WordPress export هستند. متن منتشرشدهٔ عمومی ممکن است اطلاعاتی داشته باشد که نخواهید در گفتگو بفرستید؛ خروجی را پیش از پیوست بازبینی کنید.

## نصب و ارسال

1. افزونه را از لینک مستقیم GitHub ZIP که در پاسخ به کاربر فرستاده می‌شود دریافت کنید.
2. WordPress: **افزونه‌ها ← افزودن ← بارگذاری افزونه**، ZIP را انتخاب و فعال کنید.
3. **ابزارها ← خروجی ممیزی سایت**: فایل اول را دانلود کنید و سپس «شروع ممیزی کامل صفحات عمومی» را بزنید تا فایل دوم ساخته شود.
4. هر دو JSON را در همین گفتگو پیوست کنید؛ اگر فایل بزرگ بود، جداگانه بفرستید. اگر توقف/سقف خروجی ثبت شده، بگویید تا مشخص شود کدام بخش نیاز به ادامه دارد.
5. بعد از دریافت فایل‌ها افزونه را غیرفعال/حذف کنید؛ سایت چیزی از خروجی‌ها ذخیره نمی‌کند.

## آزمون و وضعیت

- syntax PHP 7.4 با parser محلی، JS با `node --check` و قیود امنیتی static-check می‌شوند؛ lint/اجرای واقعی WordPress تا زمان نصب روی سایت مالک ممکن نیست.
- ZIP از همان سورس افزونه ساخته می‌شود و در GitHub با فایل مستقیم ارائه می‌شود، چون آپلود asset Release در محدودیت شبکهٔ این sandbox به `uploads.github.com` EOF داد.
- تحلیل SEO مرحله‌ای پس از دریافت خروجی‌ها انجام می‌شود. هیچ تعمیر یا انتشار سایت بدون تأیید صریح انجام نمی‌دهم.
