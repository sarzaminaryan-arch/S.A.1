## اتصال اولیه به دادهٔ عملکرد

GA4 گزارش‌شده برای ۱۶ سپتامبر تا ۱۵ اکتبر ۲۰۲۶، بیشترین Views را برای عنوان «شناخت کامل استان‌ها و شهرستان‌ها» (۱۱۱)، آموزش کمپینگ و بقا (۸۲)، خانه (۷۳) و «دینی‌ها» (۴۷) نشان می‌دهد. این داده **صفحهٔ ورودی/کانال/جستار گوگل را نشان نمی‌دهد**؛ لذا فقط نشانه‌ای اولیه است که صفحات مرجع جغرافیا و راهنماها دیده شده‌اند. برای انتخاب خوشهٔ اول باید views را با Search Console و landing-page report تطبیق داد.

## قاعدهٔ تخصیص نهایی

برای هر خوشه، پس از دریافت URLهای زنده و Search Console، یک ردیف تکمیل شود: `query خام | query نرمال‌شده | intent | URL فعلی | impressions/clicks/CTR/position | تصمیم (بهینه‌سازی/ادغام/ساخت/عدم اقدام) | اطمینان | دلیل`. اگر دو URL برای query واحد impression می‌گیرند، ابتدا نقش هر دو و canonical/لینک داخلی بررسی شود؛ به‌صورت خودکار هیچ صفحه‌ای حذف یا redirect نشود.
