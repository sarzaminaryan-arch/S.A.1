# سیاست سبک‌سازی مخزن S.A.1

از 2026-10-05 مخزن فقط فایل‌های منبع و عملیاتی را نگه می‌دارد:

- `.github/` برای انتشار خودکار قالب؛
- `wp-content/themes/sarzaminaryan-child/` برای کد واقعی قالب؛
- `docs/` برای مستندات کوچک و کاربردی؛
- `data-model/` برای مدل داده؛
- `skill-SA-agent/` و فایل‌های راهنمای ریشه برای قواعد کار عامل.

موارد زیر نباید داخل Git commit شوند:

- ZIPهای نصب، بسته‌های انتشار و checksumها؛
- فولدر `downloads/`؛
- بسته‌ها و خروجی‌های تصویری حجیم مثل `assets/featured/`؛
- فایل‌های موقت، خام، خروجی ابزارها و تصاویر یک‌بارمصرف.

اگر به فایل ZIP نصب نیاز است، آن را فقط به‌عنوان GitHub Release asset منتشر کنید. اگر به آرشیو تصویری یا بسته محتوایی نیاز است، آن را بیرون از tree اصلی نگه دارید یا فقط لینک انتشار/آرشیو را در مستندات سبک ثبت کنید.

> توجه: حذف فایل‌ها از آخرین commit، working tree و بسته‌های آینده را سبک می‌کند. کوچک‌سازی واقعی کل تاریخچه GitHub به history rewrite جداگانه نیاز دارد و فقط با تأیید صریح انجام می‌شود، چون tagها، releaseها و cloneهای قبلی را تحت تأثیر قرار می‌دهد.
