# فاز ۱ — جمع‌وجورسازی CSS زیر شناسنامه

تاریخ: 2026-10-19 · برنچ نشست: `arena/41372fa2-s-a-1`

## دامنه و نتیجه

- تنها فایل اجرایی تغییرکرده: `wp-content/themes/sarzaminaryan-child/assets/css/child.css`.
- موبایل تا عرض 760px: عنوان و فاصله‌های امتیازدهی کوچک‌تر؛ هفت انتخاب ستاره در شبکهٔ یک‌ردیفهٔ ۷ستونه. ارتفاع لمس حداقل 44px حفظ شده است. توضیح راهنما در صورت نیاز چندخطی می‌شود؛ چیزی حذف یا بریده نمی‌شود.
- اعلان موفقیت: فونت `.78rem`، پدینگ `.3rem .55rem`، عرض متناسب با متن و حداکثر `min(100%, 32rem)`؛ پیام بلند بدون سرریز می‌شکند. متن و نقش `status` عوض نشده است.
- فهرست: فاصلهٔ شبکه 1px، پدینگ عمودی لینک 2px، شماره‌ها 22px؛ ارتفاع ردیف‌های معمول از 40px موبایل / حدود 43px دسکتاپ به 28px رسید. متن بلند، تورفتگی زیرسرفصل‌ها، اسکرول و فوکوس حفظ شدند.
- هیچ selector عمومی یا selector شناسنامه تغییر نکرده؛ تمام اصلاحات محدود به `.cc-rating` و `.sa-toc` است.
- CSS در فایل مشترک قرار دارد و محدود به شناسه یا مقالهٔ نمونه نیست؛ پس از نصب روی تمام صفحات استفاده‌کننده از این مؤلفه‌ها اثر می‌کند. امتیازدهی طبق قالب موجود فقط برای نوع `city` نمایش داده می‌شود؛ به سایر انواع افزوده نشده است.
- تعداد محتوای مقالهٔ تغییرکرده: **۰**. هیچ نوشتن دیتابیس، واردسازی یا تغییر مقاله‌ای انجام نشد. شمار ۴۸۰ مقاله، دامنهٔ اعلامی مالک است؛ تعداد مقالات سایت زنده در این محیط تأیید نشده است.
- نسخه تغییر نکرده و Release نصبی ساخته نشده است. `child.css` از قبل با `filemtime` نسخه‌گذاری می‌شود؛ هیچ PHP یا هدر نسخه برای این فاز تغییر نکرد.

## بررسی و آزمون

`tests/test-template-cleanup.cjs` یک fixture محلی با ساختار مؤلفه‌های `CC_UI::rating_block()` و `sa_toc_markup()`، CSS واقعی والد/فرزند/مشارکت و فونت محلی Vazirmatn می‌سازد. API رأی mock است؛ هیچ درخواست یا رأیی به سایت زنده ارسال نمی‌شود.

- Chromium / Playwright: **قبول** در عرض‌های 320، 360، 390، 430، 640، 760، 768، 1024 و 1440px (RTL).
- هفت ستارهٔ موبایل روی یک خط، عرض هدف حداقل 24px و ارتفاع حداقل 44px: قبول.
- عنوان بلند «امتیاز کاربران به شهرستان بوئین و میاندشت» روی یک خط در عرض‌های موبایل آزموده‌شده: قبول.
- عدم سرریز افقی ستاره‌ها و فهرست، شکستن پیام بلند و کوچک‌ماندن اعلان کوتاه: قبول.
- کاهش ارتفاع ردیف معمول فهرست حداقل ۲۴٪: قبول (عملاً حدود ۳۰–۳۵٪).
- مقایسهٔ computed style قاب و خانهٔ شناسنامه پیش/پس: بدون تغییر.
- هندسهٔ دکمه‌های امتیازدهی دسکتاپ پیش/پس: بدون تغییر.
- مسیر انتخاب ستاره → ثبت رأی → پیام موفقیت → قفل هفت دکمه و مخفی‌شدن ثبت، با JS اصلی و API mock: قبول.
- فوکوس صفحه‌کلید فهرست: قبول.
- تصاویر fixture در 320، 390 و 1440px خارج از مخزن ساخته شدند؛ تصویرهای 320 و 1440 بازبینی بصری شدند. تصویر و وابستگی حجیم در گیت ثبت نمی‌شود.
- `node --check` و `git diff --check`: قبول.
- PHP تغییر نکرد؛ PHP محلی نیز نصب نیست، پس ادعای lint یا اجرای کامل وردپرس نداریم.

اجرای مجدد (Playwright و Chromium باید در محیط تست فراهم باشند):

```sh
NODE_PATH=/path/to/qa/node_modules CHROMIUM_PATH=/path/to/chromium \
  node wp-content/themes/sarzaminaryan-child/tests/test-template-cleanup.cjs
```

در این محیط Chromium از بستهٔ npm `@sparticuz/chromium` تأمین شد و کتابخانه‌های همراه آن با `LD_LIBRARY_PATH=/tmp/al2023/lib` بارگذاری شدند. هیچ وابستگی به محصول یا قالب اضافه نشده است.
