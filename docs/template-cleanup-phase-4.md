# فاز ۴ — کارت‌های جاذبه‌ها و شهرهای هم‌استانی

تاریخ: 2026-10-19 · برنچ `arena/41372fa2-s-a-1` · قالب `2.22.23`

## نتیجه

**🟢 پیاده‌سازی و QA محلی؛ 🟡 نصب و پوشش زنده هنوز تأیید نشده است.**

- یک بخش «جاذبه‌های شهرستان» جایگزین جدول جاذبه‌ها و چهار گروه جدا (از جمله تاریخی/زیارتی) در خروجی تولیدشدهٔ قالب شهرستان شد. نام تکراری یک‌بار می‌آید؛ یادداشت و فاصلهٔ موجود حفظ می‌شوند. سقف نمایشی ۸ جاذبه/۱۲ هم‌استانی برای این خروجی برداشته شد.
- ستون/برچسب نمایشی «نوع»، برچسب‌هایی مثل «بکر و کمتر دیده‌شده» و کدهای زائد جدول از این بخش حذف شدند؛ نه طبقه‌بندی‌های دیتابیس یا فرم‌های مدیریتِ نامرتبط.
- جاذبه‌های دارای صفحهٔ منتشرشده و شهرهای هم‌استانی، کادرهای لینک‌دار تمام‌سطح با پس‌زمینهٔ `#101f3d`، متن سفید و خط زرد `#ffe568` با glow دقیقاً چسبیده به پایین دارند؛ هر دو از یک کلاس و CSS قالب استفاده می‌کنند.
- چیدمان RTL: دو ستون موبایل، سه ستون از 600px، چهار ستون از 1000px و یک ستون زیر 301px. برچسب بلند بدون حذف متن می‌شکند؛ حداقل ارتفاع لینک 64px و فوکوس صفحه‌کلید مشخص است. بدون JavaScript یا دارایی خارجی تازه.
- کارت‌ها به‌صورت بخش مستقل **زیر شناسنامه** هستند؛ منطق داده و HTML هدر/خانه‌های شناسنامه با نسخهٔ قبلی byte-identical و CSS قدیمی به‌طور کامل دست‌نخورده است. توضیح‌های کوتاه زیر کارت نیز حفظ شدند.
- شناسه‌های `county-visit`، `county-attractions` و `county-siblings` حفظ شدند؛ دو بخش در TOC ثبت می‌شوند. بخش خالی چاپ نمی‌شود؛ هم‌استانیِ خود صفحه حذف می‌شود و صفحات draft لینک نمی‌شوند.

## استثنای داده‌ای، بدون جعل لینک

رکوردهای قدیمی POI ممکن است فقط نام/فاصله/توضیح داشته باشند و صفحهٔ منتشرشده نداشته باشند. این موارد در همان بخش به‌صورت فهرست متنی کوچک حفظ می‌شوند؛ **نه لینک ساختگی، نه کادر با glowِ ظاهراً قابل‌کلیک**. همهٔ کادرهای جدید واقعاً لینک هستند. برای تبدیل بقیه به کادر، مقصد معتبر و منتشرشده لازم است؛ این فاز مقاله یا ادعای تازه نمی‌سازد. تعداد چنین مواردی در سایت زنده بدون خروجی واقعی مشخص نیست.

## دامنه و تعداد

- **۰ رکورد دیتابیس و ۰ متن ذخیره‌شدهٔ مقاله ویرایش شد.** تغییر، سراسری در قالب مشترک `city` و پس از نصب است؛ تعداد واقعی صفحات متاثر در مجموعهٔ ۴۸۰تایی در دسترس نیست.
- متن‌های مستقل داخل `post_content` که شاید همین عنوان‌ها را داشته باشند، بدون مشاهدهٔ متن واقعی دستکاری نشده‌اند. ادغام این فاز مربوط به بلوک‌های تولیدشدهٔ قالب است؛ پایان ویرایش محتوایی فاز ۳ یا بررسی همهٔ بدنه‌های سایت ادعا نمی‌شود.
- نسخهٔ نصب‌شده طبق آخرین گزارش مالک عیناً `2.12.21` ثبت است؛ به `2.22.21` تبدیل نشده و نصب 22/23 فرض نمی‌شود. بستهٔ 23 ادامهٔ سورس 22 است: پایهٔ رسمی 14 + فازهای ۱/۲ + فقط فاز ۴؛ تغییرات نامرتبط نسخه‌های 15–21 وارد نشده‌اند.

## آزمون‌ها

- parser تمام **۱۴۱ PHP** و **۱۴ فایل تست**، هرکدام در PHP-WASM 7.4 و 8.5 قبول؛ stdout برای Fatal/FAIL هم بررسی شد.
- تست جدید `tests/test-county-destinations.php`: رندر واقعی partial با ۱۱ جاذبهٔ ساختگی منتشرشده، ادغام تکراری‌ها/میراث، حفظ توضیح‌ها، نبود نوع، escape متن مخرب، حذف draft/self، anchor/TOC، عدم mutation، خروجی خالی و نوع غیرشهرستان.
- `tests/test-county-destinations.cjs`: Chromium، CSS والد/RTL/فرزند و فونت محلی، **280/320/360/390/430/600/768/1024/1440px**؛ ستون‌ها، ترتیب RTL، نبود سرریز، رنگ‌ها، خط bottom=0، glow و لمس/فوکوس/ناوبری به URL ساختگی قبول. هیچ درخواست زندهٔ سایت انجام نشد.
- بازآزمون فاز ۱ در ۹ عرض: شناسنامه بدون تغییر CSS، فهرست فشرده، ستاره‌های یک‌ردیفه و ثبت رأی mock قبول. رگرسیون فاز ۲ نیز قبول؛ ۱۰۵ مقالهٔ همراه قالب بدون تغییر، ۴۸۰ بدنهٔ ساختگی همچنان قبول.
- `build_theme_data.py --check` (۶۷ راهنما)، syntax تست Node و `git diff --check` قبول. تست PHP جدید به workflow انتشار اضافه شده است.
