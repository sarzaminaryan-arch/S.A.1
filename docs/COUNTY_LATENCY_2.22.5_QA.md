# تأخیر صفحهٔ شهرستان — اصلاح ۲٫۲۲٫۵

تاریخ: ۲۰۲۶-۱۰-۱۸ · شاخه: `arena/a32fb27a-s-a-1`

## گزارش مالک

کلیک روی شهرستان ابتدا بی‌اثر به نظر می‌رسد، ولی پس از حدود ۱۰ تا ۱۵ ثانیه
صفحهٔ مقصد باز می‌شود؛ استان‌ها و دیدنی‌ها چنین تأخیری ندارند. این گزارش
نشانهٔ انتظار برای بارگذاری است، نه مدرک خراب‌بودن href یا جلوگیری از کلیک.

## یافتهٔ قابل اثبات در کد

از نسخهٔ ۲٫۲۲٫۳، `sa_county_sources()` برای تک‌تک آدرس‌های منابعِ مقاله و
FAQ، `wp_http_validate_url()` را در درخواست بازدیدکننده فراخوانی می‌کرد.
برخلاف تصورِ درج‌شده در توضیح قدیمی، این تابع صرفاً تجزیهٔ رشته نیست:
پیاده‌سازی هستهٔ وردپرس برای دامنهٔ بیرونی `gethostbyname()` اجرا می‌کند.
بنابراین صفحهٔ شهرستان پیش از اتمام پاسخ می‌تواند به DNS دامنه‌های منابع
وابسته شود؛ فهرست نامزدها نیز پیش از اعمال سقف ده بررسی می‌شد.

مرجع کد هسته: [WordPress/wp-includes/http.php](https://github.com/WordPress/WordPress/blob/master/wp-includes/http.php)،
تابع `wp_http_validate_url`. این بررسیِ کد است، نه پروفایل شبکهٔ هاست مالک.

## اصلاح محدود

- `sa_county_source_url()` فقط ساختار URL نمایشی را محلی بررسی می‌کند؛ هیچ
  resolve، HTTP probe یا درخواست شبکه‌ای برای نمایش منابع انجام نمی‌شود.
- فقط HTTP(S)، دامنهٔ دارای ساختار معتبر و پورت‌های ۸۰/۴۴۳/۸۰۸۰ پذیرفته می‌شوند؛
  IP مستقیم، نام محلی/داخلی، نام کاربری/رمز، کنترل‌کاراکتر و URL معیوب رد می‌شوند.
- این تابع مجوز واکشی URL نیست؛ برای درخواست‌های خروجی، اعتبارسنجی SSRF و
  HTTP API امن وردپرس همچنان لازم است و هیچ مسیر واکشی موجود تضعیف نشده است.
- حذف گوگل، یک ویکی‌پدیا، حذف منبع تکراری، اولویت مرجع رسمی و سقف ده حفظ شد.
- ظاهر، جاوااسکریپت کلیک، URLها، rewrite، دادهٔ مقاله، رأی‌ها، والد، افزونه‌ها
  و wp-config تغییر نکردند. سیاست عدم نمایش یادداشت تحریریه نیز حفظ شد.

## آزمون

- `test-county-source-performance.php`: شبیه‌ساز اعتبارسنج هسته با تأخیر مصنوعی،
  ۴۰ نامزد منبع، شمارش فراخوانی‌ها؛ کد قبلی در الزامِ صفر فراخوانی DNS شکست خورد.
- پس از اصلاح: صفر فراخوانی اعتبارسنج DNS، حفظ سقف ده و کنترل منابع/URLهای
  معیوب و محلی. نمونهٔ اجرای محلی ۱۹ میلی‌ثانیه برای ۴۰ نامزد بود؛ این عدد
  زمان بارگذاری سایت زنده نیست و آستانهٔ زمانی شکننده‌ای در تست وجود ندارد.
- هر ۱۴ فایل آزمون مستقل و parse هر ۱۴۱ فایل PHP روی PHP-WASM 8.5.10 موفق شد؛
  `git diff --check` موفق و آزمون جدید به CI انتشار اضافه شد.

## پذیرش روی سایت

پس از نصب نسخهٔ ۲٫۲۲٫۵، کش صفحه/CDN پاک شود؛ یک شهرستان از صفحهٔ استان،
فهرست شهرستان‌ها و مقالهٔ دیگر باز شود. زمان درخواست document در Network
مرورگر برای یک شهرستان ثابت، قبل/بعد و در شرایط کش یکسان مقایسه شود.
نقشه، منابع، FAQ و رأی پنج‌ستاره هم کنترل شوند.

به سایت/لاگ/PHP profiler زنده دسترسی نداریم؛ بنابراین رفع تمام عواملِ احتمالی
کندی یا زمان پاسخ جدیدِ هاست ادعا نمی‌شود. اگر تأخیر باقی بود، URL نمونه و
زمان Waiting/TTFB درخواست document برای بررسی دیتابیس، کش یا DNS هاست لازم است.
تغییر rewrite یا حذف منبع/نقشه برای پنهان‌کردن مشکل انجام نشده است.
