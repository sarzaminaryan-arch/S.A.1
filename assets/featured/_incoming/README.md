# _incoming/ — تصاویر خام هنوز پردازش‌نشده

این پوشه محل موقت آپلودهای خام مالک است که هنوز به قالب نهایی `assets/featured/{provinces,counties}/{slug}.webp`
تبدیل نشده‌اند (تغییر نام به نامک استاندارد، برندینگ با فونت Vazirmatn، فشرده‌سازی ≤ ۳۰۰ کیلوبایت). آپلودهای خامی
که قبلاً کامل پردازش و جایگزین شدند (imagetool ۱۴/۱۵، «تصاویر شاخص سه استان اول»، «isfahan image») در پاک‌سازی
مخزن ۱۴۰۵/۰۷/۰۸ حذف شدند چون نسخهٔ نهایی‌شان از قبل در `assets/featured/` موجود بود.

| فایل | وضعیت |
|---|---|
| `imagetool-16-pending-county-images.zip` | ۸ عکس خام (شامل یک طرح جایگزین برای «اصلاندوز»/Aslanduz، شهرستان اردبیل، با سبک متفاوت از استاندارد فعلی پوشهٔ `assets/featured/counties/ardabil/`) — هنوز بررسی/جایگزینی نشده |
| `alborz-county-images-raw.zip` | ۶ عکس خام برای شهرستان‌های البرز — هیچ‌کدام هنوز در `assets/featured/counties/` قرار نگرفته‌اند (پوشهٔ `counties/alborz/` هنوز ساخته نشده) |

قبل از پردازش، بررسی شود کدام شهرستان از فهرست ۹ استانِ دارای پوشهٔ `counties/` هنوز عکس ندارد.
