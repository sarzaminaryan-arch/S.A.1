قالب فروشگاهی مینیمال، فارسی و راست‌چین برای وردپرس و ووکامرس.

== توضیح ==

MR369L یک قالب بلوکی (Full Site Editing) است که برای فروشگاه‌های اینترنتی فارسی‌زبان ساخته می‌شود:

* راست‌چین از پایه با ویژگی‌های منطقی CSS (نه فقط تغییر تراز متن).
* تایپوگرافی فارسی با فونت وزیرمتن (محلی، بدون CDN، مجوز OFL).
* موشن تایپوگرافی سبک با CSS خالص و احترام کامل به «کاهش حرکت» سیستم‌عامل.
* سازگاری نمایشی با ووکامرس بدون دست‌کاری هستهٔ افزونه و بدون تغییر ساختار داخلی بلوک‌ها.
* صفر جاوااسکریپت اختصاصی و صفر درخواست بیرونی.
* یک صفحهٔ تنظیمات ساده زیر «ظاهر ← تنظیمات MR369L».

== نصب ==

1. فایل ZIP را از GitHub Releases دانلود کنید.
2. در پیشخوان: «ظاهر ← پوسته‌ها ← افزودن پوستهٔ تازه ← بارگذاری پوسته».
3. قالب را فعال کنید و از «ظاهر ← ویرایشگر» چیدمان و منو را تنظیم کنید.
4. اگر ووکامرس نصب است، صفحه‌های سبد و تسویه را به قالب‌های خودشان اختصاص دهید.
