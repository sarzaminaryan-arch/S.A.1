# تغییرات قالب MR369L

همهٔ تغییرات مهم این قالب در این فایل ثبت می‌شوند.
قالب از نسخه‌گذاری معنایی (Semantic Versioning) پیروی می‌کند.

## [0.1.0] — 2026-10-12

### افزوده شد
- اسکلت قالب بلوکی: `style.css`, `theme.json` (نسخهٔ ۳), `functions.php`, `templates/`, `parts/`.
- سیستم طراحی در `theme.json`: پالت ۹ رنگ، مقیاس تایپ فارسی، مقیاس فاصله، توکن‌های شعاع/سایه/موشن.
- لایهٔ موشن تایپوگرافی CSS خالص (`assets/css/typography-motion.css`) با سه سطح و پشتیبانی `prefers-reduced-motion`.
- صفحهٔ تنظیمات مالک («ظاهر ← تنظیمات MR369L») با Settings API و تنظیم سطح موشن.
- قالب‌های بلوکی: `index`, `front-page`, `page`, `page-wide`, `single`, `archive`, `search`, `404`.
- الگوهای آماده: هیرو با موشن تایپوگرافی، نشان‌های اعتماد، نوار اعلان.
- لینک «پرش به محتوا» و کلاس‌های `body` برای سطح موشن و وضعیت ووکامرس.
