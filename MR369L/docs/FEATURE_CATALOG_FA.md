| | |
|---|---|

> **سیاست پیش‌فرض ایمن:** گزینه‌هایی که رفتار فروشگاه را عوض می‌کنند، هزینهٔ کارایی دارند، داده جمع می‌کنند یا بر دسترس‌پذیری اثر می‌گذارند، پیش‌فرض **خاموش** هستند. هر گزینه با `sanitize_callback`، `capability` و برچسب دسترس‌پذیر ثبت می‌شود.
