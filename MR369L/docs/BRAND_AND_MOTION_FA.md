## ۳) اصول زیبایی‌شناختی (Design Aesthetic Principles)

۱. **سکوت بصری (Visual Silence):** فضای خالی، ابزار اصلی است. حذف هر عنصری که به تصمیم خرید کمک نمی‌کند.
۲. **سلسله‌مراتب از راه اندازه و فاصله، نه رنگ‌های فریادگر:** تنها یک رنگ تأکیدی در هر نما.
۳. **راست‌چینی به‌عنوان اصل، نه تعمیر:** شبکه‌ها و فاصله‌ها از ابتدا منطقی (logical) تعریف می‌شوند.
۴. **تیپوگرافی حامل شخصیت:** وزن‌های محدود (۳ وزن)، ارتفاع خط فارسی (۱٫۸)، بدون letter-spacing در فارسی.
۵. **حرکت معنادار (Motion with Meaning):** حرکت باید **وظیفه** داشته باشد — هدایت نگاه، تأیید کنش، اعلام تغییر وضعیت. حرکت تزئینی بی‌هدف حذف می‌شود.
۶. **دسترس‌پذیری جزئی از زیبایی:** کنتراست کافی، فوکوس دیدنی و پشتیبانی reduced-motion بخشی از «زیبا بودن» تعریف می‌شوند، نه هزینهٔ اضافه.
۷. **ثبات توکن:** هر رنگ/فاصله/اندازه از توکن می‌آید؛ مقدار دستی (magic number) ممنوع.

## ۵) سیستم موشن تایپوگرافی (Animated Typography) — مشخصات فنی

### ۵-۱) اصول سخت موشن در MR369L

| # | اصل | قاعدهٔ فنی |
|---|---|---|
| M1 | **بدون جاوااسکریپت** | همهٔ موشن‌ها با CSS (`@keyframes`, `animation-delay`, `animation-timeline`) |
| M2 | **محتوا هرگز پنهان نمی‌ماند** | حالت پایه = متن کامل و خوانا؛ انیمیشن فقط «افکت ورود» است. اگر مرورگر پشتیبانی نکند یا JS/CSS ناقص بار شود، متن دیده می‌شود |
| M3 | **احترام به کاهش حرکت** | کل موشن داخل `@media (prefers-reduced-motion: reduce)` خاموش می‌شود (بدون استثنا) |
| M4 | **پشتیبانی تدریجی (Progressive Enhancement)** | انیمیشن‌های وابسته به اسکرول داخل `@supports (animation-timeline: view())` و انیمیشن‌های ورودی داخل `@supports (animation-timeline: auto)` یا شرط معادل |
| M5 | **بودجهٔ کارایی** | حجم CSS موشن ≤ ۶KB خام؛ صفر layout shift؛ فقط `transform` و `opacity` و `clip-path` انیمیت می‌شوند (بدون `width/height/top/left`) |
| M6 | **کنترل مالک** | سه سطح: `خاموش` / `ملایم` (پیش‌فرض) / `نمایشی`. سطح در تنظیمات قالب قابل تغییر است |
| M7 | **مهار متوالی (Stagger) با متغیر CSS** | تأخیر هر عنصر با `--motion-index` تعیین می‌شود؛ مقدار در مارک‌آپ الگوها (بدون JS) |
| M8 | **بدون انیمیشن در محتوای حیاتی خرید** | قیمت، موجودی، دکمهٔ افزودن به سبد، و پیام‌های خطا هرگز انیمیت تزئینی نمی‌شوند (فقط تغییر وضعیت ساده) |

### ۵-۲) فهرست انیمیشن‌های مصوب (Motion Inventory)

| ID | نام | کاربرد | تکنیک CSS | زمان | حریم کاربرد | وضعیت |
|---|---|---|---|---|---|---|
| MO-01 | `rise-in` | ورود کلمه‌به‌کلمهٔ عنوان هیرو | `translateY(0.6em)` + `opacity` با `--motion-index` | 520ms، easing `cubic-bezier(.2,.7,.2,1)` | فقط `h1/h2` هیرو و سرتیتر بخش‌ها | **implemented** |
| MO-02 | `mask-wipe` | نمایان‌شدن تیتر با پردهٔ برشی (جایگزین تایپ‌رایتر، مناسب فونت تناسبی فارسی) | `clip-path: inset(0 100% 0 0)` → `inset(0 0 0 0)` | 700ms | فقط در سطح «نمایشی» | **implemented** |
| MO-03 | `underline-draw` | کشیده‌شدن زیرخط لینک/دکمه در hover/focus | `background-size: 0% 1px` → `100% 1px` | 240ms | همهٔ لینک‌های درون متن و دکمه‌ها | **implemented** |
| MO-04 | `fade-raise` | ورود کارت‌ها/بلوک‌های محتوا | `opacity` + `translateY(12px)` | 420ms با تأخیر پله‌ای ۴۵ms | شبکهٔ محصولات و کارت‌ها (کلاس `mr-stagger`) | **implemented** |
| MO-05 | `title-reveal-on-scroll` | ورود تیتر بخش‌ها هنگام اسکرول | `animation-timeline: view()` داخل `@supports` | محدودهٔ `entry 0% → cover 32%` | تیتر بخش‌های صفحهٔ اصلی | **implemented** |
| MO-06 | `Ticker` (نوار اعلان) | حرکت آرام متن اعلان ارسال/تخفیف | `translateX` خطی + `prefers-reduced-motion` + توقف در hover/focus | 22s چرخهٔ بی‌پایان | فقط نوار اعلان؛ نسخهٔ تکراری تزئینی `aria-hidden` دارد | **implemented** |
| MO-07 | `focus-ring` | نشانگر فوکوس دیدنی (بدون انیمیشن بی‌پایان) | `outline: 2px` + `outline-offset` | بدون زمان‌بندی | همهٔ عناصر تعاملی | **implemented** |
| MO-08 | `state-shift` | تغییر وضعیت دکمه (بارگذاری/موفق) | تغییر رنگ/متن آمادهٔ ووکامرس + انتقال ملایم | 200ms | دکمهٔ افزودن به سبد | deferred (نیازمند ووکامرس) |

**انیمیشن‌های ردشده (با دلیل):** تایپ‌رایتر حرف‌به‌حرف روی فونت تناسبی فارسی (پرش عرض)، پلکسی/اسلایدر تمام‌صفحه (LCP و CLS)، شمارندهٔ عددی با JS (نیاز به JS و خطر اعلام عدد اشتباه)، افکت پارالاکس اسکرول (INP و دل‌به‌هم‌ریختگی)، انیمیشن روی قیمت و موجودی (اصل M8).

### ۵-۳) نمونهٔ پیاده‌سازی مرجع (طرح اولیه، در WP-3.3 نهایی می‌شود)

```css
/* --- MR369L typography motion (نمونهٔ مرجع) --- */
.mr-motion-word {
  display: inline-block;
  animation: mr-rise-in .52s cubic-bezier(.2,.7,.2,1) both;
  animation-delay: calc(var(--motion-index, 0) * 70ms);
}
@keyframes mr-rise-in {
  from { opacity: 0; transform: translateY(.6em); }
  to   { opacity: 1; transform: none; }
}

/* بدون پشتیبانی/با کاهش حرکت: متن کامل و بی‌حرکت */
@media (prefers-reduced-motion: reduce) {
  .mr-motion-word,
  [class*="mr-motion-"] { animation: none !important; transition: none !important; }
}
```

```html
<!-- مارک‌آپ الگو (بدون جاوااسکریپت): مهار متوالی با متغیر CSS -->
<h1 class="mr-hero__title">
  <span class="mr-motion-word" style="--motion-index:0">خریدی</span>
  <span class="mr-motion-word" style="--motion-index:1">ساده،</span>
  <span class="mr-motion-word" style="--motion-index:2">سریع،</span>
  <span class="mr-motion-word" style="--motion-index:3">مطمئن</span>
</h1>
```

> **نکتهٔ دسترس‌پذیری:** شکستن تیتر به `<span>` درون یک `<h1>` ساختار سرویس‌دهنده را حفظ می‌کند (متن پیوسته خوانده می‌شود)؛ ولی اگر فاصلهٔ بین spanها در خواندن مشکل ایجاد کند، از `&nbsp;` یا `display:inline` با فاصلهٔ طبیعی استفاده می‌شود. این مورد در WP-3.3 با آزمون ساختاری بررسی می‌شود.

### ۵-۴) معیار پذیرش WP-3.3 (تکرار از سند بسته‌ها)
1. با `prefers-reduced-motion: reduce` هیچ انیمیشنی اجرا نشود (شاهد: بازبینی CSS + اسکن خودکار).
2. با CSS ناقص/مسدود، متن کامل خوانده شود (شاهد: ساختار پایه = opacity 1).
3. حجم `typography-motion.css` ≤ ۶KB.
4. صفر جاوااسکریپت اختصاصی و صفر layout shift (بدون انیمیت ویژگی‌های چیدمانی).
5. سه سطح موشن در تنظیمات قالب کار کند و در پیش‌فرض «ملایم» باشد.
